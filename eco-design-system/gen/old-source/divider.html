Divider

A divider is a 1px line that separates content groups, so users can scan and organize information. It is decorative and never interactive.

Every example on this page is the real component. Specification: .claude/skills/eco-divider/SKILL.md.

Accessibility

    
TopicRule

      
SemanticsUse <hr> (or role="separator") when the line separates content for everyone. Use aria-hidden="true" when it is only visual.

      
ColorNever rely on color alone. If the line carries meaning, the structure (headings, lists) must also show the grouping.

      
ContrastEnsure enough contrast if the line carries meaning. Prefer Primary or Tertiary over Secondary.

    

  






  

    
Code

    
Copy the markup you need, then add the CSS once per page. The CSS is read from this page’s stylesheet, so it is always what you see above.

    
HTML
<!-- Horizontal -->
<hr class="divider" />
<hr class="divider divider--secondary" />
<hr class="divider divider--tertiary" />

<!-- Vertical, inside a flex row -->
<span class="divider divider--vertical" role="separator" aria-orientation="vertical"></span>

<!-- Visual only -->
<span class="divider" aria-hidden="true"></span>

Usage

    
Add a divider only when spacing alone does not separate the content. A full-width boundary between page sections uses .page-divider from eco-section.

    

      
Do
  • Separate distinct groups when whitespace is not enough.
  • Create hierarchy between types of information.
  • Set the space around it from the parent gap.
  • Use Primary by default, Tertiary for short side-by-side items.

      
Don’t
  • Overuse dividers: they create visual clutter.
  • Add a line only for decoration.
  • Use a divider where a heading or label is clearer.
  • Add margin to the divider itself.
