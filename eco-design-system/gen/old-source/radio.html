Radio button

A radio button lets the user choose exactly one of two or more mutually exclusive options. Choosing one clears the others in the group.

Every example on this page is the real component. Click, tab and use the arrow keys to try it. Specification: .claude/skills/eco-radio/SKILL.md.

Sizes

    
Large is the default. Small (class .form-radio-item--sm) is for dense layouts. The size does not change with the breakpoint; only the Large label does.

    

    
Group with a default

    
Related options sit in a fieldset with a legend, stacked vertically, with one option preselected. A hint message sits under the label of the option it explains.

    

    
Horizontal and disabled

    
Horizontal only for two short options: it hides the link between radio and label for longer lists. A disabled group keeps the selection visible.

Anatomy & specs

    


The 4px margin around the circle leaves exactly room for the focus ring (2px gap plus 2px line), so focusing never shifts the layout. Gap between circle and label is 8px, between label and hint 4px.

Usage

    


Radio, checkbox, switch and segment control look alike but do different jobs. Choose by what the user is deciding.

    
The user…Use
picks exactly one of two or more optionsRadio
picks any number of options, saved on submiteco-checkbox
turns one setting on or off, with immediate effecteco-switch
switches between two related views or filterseco-pill-segment-control
picks one value from a long listeco-select

    

      
Do
  • Preselect a default option in every group.
  • Stack options vertically and wrap input and text in one label.
  • Give the group a legend.
  • Use Small only in dense layouts.

      
Don’t
  • Use radios for multi-select. Use checkboxes.
  • Lay out more than two options horizontally.
  • Draw the circle with an image or SVG file.
  • Hardcode colors: use the tokens.
