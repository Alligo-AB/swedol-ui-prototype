Select

A select lets the user choose one option from a list. It looks and behaves like an input field, with a dropdown arrow. It opens the ECO Menu as its list.

Every example on this page is the real component. Click, tab and choose an option to try it. Specification: .claude/skills/eco-select/SKILL.md.

Sizes

    
Large is for standard forms, Small for compact surfaces, XSmall for dense tables and filters (desktop only: on mobile it is not available, use Small). The list is the Menu: Large field opens a Large menu, Small and XSmall open a Small menu.

    

    
Messages

    
The message sits below the field in body-sm. Hint text is neutral; error and success change the border and message color. An error message has a leading icon so color is never the only signal.

Anatomy & specs

    


The arrow is a 24px icon placed 12px from the right edge. The select keeps at least 40px of right padding so text never runs under it. The focus ring is a separate element 3px outside the box, so focusing never changes the layout.

Behavior and accessibility

    
InputResult
ClickOpens the Menu under the field (no ring on mouse). Click a row to choose; click outside to close.
TabThe blue ring shows on keyboard focus only (body.keyboard-nav).
Enter, Space, Arrow keysOpen the Menu on the chosen row. Up and Down, Home and End move; Enter or Space choose; Escape closes and returns focus to the field; Tab closes.
PlaceholderA first option with value="" (disabled, hidden) shows the placeholder in text-tertiary.
LabelAlways a label with for and id. A placeholder is never the label.
ErrorSet aria-invalid="true" and point aria-describedby at the message.
DisabledNot focusable. Grey fill, light border, text-disabled text and arrow.

    
Hover is border-hover (#333333, the same value as border-dark). On keyboard focus the box keeps border-input-default and only the ring shows, like the input. Active is read from the chosen option with :has(), so no script is needed.

Usage

    


Choose the control by how many options there are and how many can be picked.

    
The user…Use
picks one value from a list of more than about fiveSelect
picks one of two to five optionseco-radio
picks any number of optionseco-checkbox
types free texteco-input

    

      
Do
  • Give every select a visible label.
  • Use a placeholder option with an empty value as the prompt.
  • Pick the size by breakpoint, like the input.
  • Show the message with the error icon.

      
Don’t
  • Use a select for two or three options: use radio.
  • Use the placeholder as the label.
  • Rely on color alone for error or success.
  • Hardcode colors or heights: use the tokens and size classes.
