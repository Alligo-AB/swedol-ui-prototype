Tabs

Tabs organise content across screens, data sets and interactions at the same level of hierarchy. A tab bar lets the user move between groups of related content without leaving the page. For content that must be read in order, use steps instead.

Every example on this page is the real component, not a picture. Specification: .claude/skills/eco-tabs/SKILL.md. Figma: Tab items, Tab bar sizes, Tab info.

Variants

  
Breakpoint

  
Primary and Secondary
Primary tabs are placed at the top of a content page, as sub-navigation when the main navigation needs more levels, or as top-level navigation where there is none (for example campaign pages). The line spans the label, 24px between tabs. Secondary tabs are always placed below primary tabs, if any. They separate related content inside an area (a card, a sheet, an information pane, sections on one page). Each tab has 16px side padding, so the line is wider than the label.

  

  
Sizes
Large, Medium and Small. Below 769px the labels are 16/16 (Large, Medium) and 14/14 (Small); from 769px 18/18 and 16/16. Large and Medium differ only in the gap to the line on mobile.

  

  
Content
Label only, label with an icon above it, or icon only. Use standalone icons only when they are globally well known, and give each an aria-label. 

  

  
Status and leading icon
A red dot marks something new in a tab. A red number badge says how many. Both sit after the label, 4px away. On an icon-only tab the dot sits at the icon’s top right. An icon can also lead the label: 24px, or 20px on Small below 769px.

  

  
On a grey surface
Background Colored in Figma: the hover line is surface-40 instead of surface-10, so it stays visible on grey. Add .tab-bar--on-grey.

  

  
Accent colour
The active line is black by default. Where a product uses its accent colour, set --tab-line-active on the bar. Swedol uses --color-accent-default; Tools is a primitive in the package (--color-primitive-color-brand-tools-accent-brand). Primary and Secondary tabs, content tabs and link tabs all follow it; the grey hover line does not change. Click a tab to see the line slide in the accent colour.

  

  
Many tabs
Tab labels appear in one row. Scrollable tabs are preferred when the titles do not fit: the bar scrolls sideways and the divider line runs the full width. Drag or scroll the bar below.

  





States
Enabled, hover, active and focus. Focus is a 2px ring around icon and label, on an enabled or an active tab alike; the line stays visible below it. Hover and focus are forced on this page. Figma has no disabled state, so none is built.

Behavior and accessibility

  
TopicRule

    
Content tabsrole="tablist" on the bar, role="tab" on each tab (button) with aria-selected and aria-controls, role="tabpanel" with aria-labelledby on the content. The selected tab has tabindex="0", the others -1.

    
Accent colourThe active line is black (surface-100) by default. Where a product uses its accent colour, set --tab-line-active on the bar: Swedol --color-accent-default; Tools is a primitive in the package (--color-primitive-color-brand-tools-accent-brand). The My Pages prototype pages use var(--brand), their own accent alias. Never restyle .tab::after or .tab-bar__indicator.

    
KeyboardTab moves into the bar, Left and Right switch tab (they wrap), Home and End go to the first and last. A tab opens as soon as it is focused. tabs.js does this.

    
Navigation tabsLinks in a nav, the current page has aria-current="page". Link tabs.js for the sliding line.

    
Icon onlyNeeds an aria-label. A status dot or number needs a text alternative where its meaning is not clear.

    
MotionOn content tabs the active line slides to the clicked tab (tabs.js moves one .tab-bar__indicator: duration-medium-2, ease-standard; off under reduced motion). Link tabs slide across the page change too: a click keeps the hover look, the next page starts the line under the old tab and slides it to the new one (the old index is kept in sessionStorage for 5 s; the bar needs the same aria-label on every page). The tab the line is travelling to keeps its grey hover line until the sliding line has arrived over it. The hover line grows from the bottom: duration-medium-2, ease-decelerate-generic, its colour fades with ease-standard. Label and icon colours change instantly, as in the My Pages nav.

    
OverflowThe bar scrolls sideways with the scrollbar hidden; the active tab is scrolled into view. The divider runs the full width.

Usage

  
The user…Use

    
moves between pages or sections at the same levelTabs

    
switches between 2–4 views or filters of the same contentPill segment control

    
chooses between a few joined options in a toolbarButton group

    
goes through content in a fixed orderSteps (stepper)

    
makes a choice that is submittedRadio

  

  
Do
  • Group content at the same level of hierarchy.
  • Put secondary tabs below primary tabs, never above.
  • Keep labels short, in one row. Prefer scrollable tabs for long titles.
  • Use only globally known icons for icon-only tabs, with an aria-label.
Don’t
  • Use tabs for content that must be read in order.
  • Nest more than two levels of tabs.
  • Make a tab with a click handler on a div.
  • Copy the CSS into a page: link tabs.css.
