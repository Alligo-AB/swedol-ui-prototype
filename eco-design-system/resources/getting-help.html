Getting help

Get support, and help us make the design system better.

How can we help?

We can help with component usage, design, best practices and any other question about the design system. If your question is outside our area, we will point you to the right information or the right person.

I need…Do this
Help with a bug, a component or accessibilityAsk in the Slack channel. We answer as soon as we can.
A component or pattern that is missingDescribe the use case in Slack, so we can see what the system should cover.
To set up my environmentRead Introduction for Developers.
To use Storybook as a content manager or marketerRead Introduction for Stakeholders.

Ask a good question

A few details help us answer faster.

  • Name the component and link to the page where you saw the problem.
  • Say which breakpoint or device it concerns.
  • Add a screenshot, and say what you expected to happen.

How you can help us

Your feedback and contributions make the design system better for everyone. Suggest improvements to the documentation, the components or anything else in our Slack channel. Tell us what is missing, unclear or out of the ordinary.

Do you have a question, comment or idea?

Let us know in the design system Slack channel.
