Foundations

Layout

The layout is the foundation for all visual elements. It guides creative choices, supports the content and gives every page the same flexible frame: a grid, five breakpoints and one spacing scale.

Every layout token from alligo-design-tokens: the breakpoints, the site margin, the gutter and the columns, read live from the package.

About the layout tokens

The layout tokens set up the grid for each breakpoint: the window widths, the site margin, the gutter and the number of columns. They are in the token package alligo-design-tokens, and the tables below are read from it when the page loads.

The margin and gutter tokens point at a step of the spacing scale (the column “Points at”), so a change to the scale reaches the grid. The spacing sizes themselves are on the Spacing tab.

Breakpoint

The window widths. The value of bp-sm, bp-md and bp-lg is the end of its range, bp-xs is the smallest supported width and bp-xl is the start of its range. bp-xl-figma is the width of the largest Figma prototype.

TokenValuePoints atDescription

Margin

The space at the left and right of the window, per breakpoint. On XLarge the margin is considered infinite: the content area stops at 1200px and is centered. site-margin-xl is the margin at 1440px, the largest prototype width.

TokenValuePoints atDescription

Gutter

The space between columns, per breakpoint. There is no gutter-xl: XLarge uses gutter-lg.

TokenValuePoints atDescription

Column

The number of columns per breakpoint. There is no column-xl: XLarge uses column-lg.

TokenValuePoints atDescription

Section padding

The top and bottom padding of the full-width sections. The package holds one set of these, the one of the Large breakpoint. The padding per breakpoint is on the Section page.

TokenValuePoints atDescription

Layout whitespace

The air between groups of components. These are the values of the Large breakpoint; space-md and space-lg of the Layout spacing step with the window.

Coverage

Open points in the package

  • The values of bp-sm, bp-md and bp-lg are range ends, not the width where the breakpoint starts. Use the start values in code (640, 769, 1024 and 1281px).
  • The column count exists twice: --dimension-breakpoint-columns-column-* (a number) and --dimension-column-* (with a px unit). Read the number one.
  • The package has one value for the tokens that have no breakpoint in their name (--dimension-breakpoint-margin, -gutter, -column): the Large one.
  • space-md and space-lg are not in the package, they come from components/css/spacing.css.
