Foundations

Typography

ECO type is modular: 20 base styles, each built from a role, a size and, when needed, a modifier. One typeface, Breuer Condensed, carries every Alligo brand.

Mobile and desktop have their own base styling and switch at 769px. Every specimen on this page is rendered from tokens.json, so it follows the package when it changes.

Overview

Breuer Condensed has three weights. Figma lists them as 500, 600 and 700; in CSS they are 100 lower. This page prints both.

Anatomy of a style

A style name reads role-size and an optional --modifier, for example label-lg--underline.

RoleThe purpose and emphasis of the text. Six roles: Display, Headline, Title, Label, Alt-Label and Body.headline-lg
SizeKeeps the scale rhythmic. Small, Medium, Large and XLarge, with availability per role.headline-lg
ModifierDescribes one specific intended use, such as underline or badge. Body styles also have italic, bold and strikethrough.label-lg--underline

The six roles

Pick the role first, then the size. Roles are ordered here from most to least emphasis in the interface.

Typesetting

How styles combine on a page: which style an HTML element gets, how long a line of text should be and how much space follows a paragraph.

Hierarchy

The default style for each element, from the ECO Figma file (Editor Default Styles). Choose the element for the document outline, then take the style from this table. On My Pages the page title is an H1 even though the table lists it as H2.

ElementDefault styleModifierToken

Display Large and Headline XLarge are both H1 styles. Use one of them on a page, never both. For a paragraph, body-lg or body-md depends on the context.

Line length

Count characters per line, spaces included. Under 40 is too narrow: the eye jumps too often. 40–60 is a good length and 60–90 is ideal. Around 100 is the margin, and past it the text is too wide. Never go beyond 130. The ruler below is set in body-sm; the same limits hold for the other body styles.

On small screens the limits are met by the layout itself: at 375px a body line holds about 40–65 characters. On desktop, cap the width of the text container instead of letting it fill the columns.

Paragraph spacing

Add the gap after a paragraph with one spacing token, never by stacking two. Use body-lg or body-md throughout an article, not both: body-lg for dedicated articles, body-md when space is tight.

Spacing after a style

The space that follows a text style, from the ECO Figma file (Style spacing). The values listed for a style are the options a designer or developer can pick from; choose one spacing token and never combine several. The blue bar shows the largest option under the sample. For body styles the value is the space before the next block, for example a heading.

StyleSampleDesktopMobile

Spacing after body-xl--preamble is 16px at every width. The Figma frame also has one unlabeled 12px example for the preamble, marked with a red frame; it is not used here.

Usage

    

      

        
Do

        
    
          
  • Pick the role by purpose first, then the size.
    • 
          
  • Use one H1 style per page: display-lg or headline-xl.
    • 
          
  • Use body-lg or body-md through a whole article, not both.
    • 
          
  • Keep body lines at 60–90 characters, never past 130.
    • 
        

      

      

        
Don’t

        
    
          
  • Set a custom font size, weight or line height next to a token.
    • 
          
  • Use Display for long text or more than a few words.
    • 
          
  • Pick a style for how big it looks and ignore the HTML element it sits in.
    • 
          
  • Add paragraph spacing by combining several spacing tokens.
