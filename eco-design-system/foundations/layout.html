Foundations

Layout

The layout is the foundation for all visual elements. It guides creative choices, supports the content and gives every page the same flexible frame: a grid, five breakpoints and one spacing scale.

Every page sits on a grid of margins, gutters and columns that adapts to the window. This tab explains the grid and shows it at each breakpoint.

GridBreakpointsSpacingTokens

Overview

To keep pages responsive and flexible in different browser widths and on different devices, every ECO layout is built on a grid. The grid has margins, gutters and columns, some with a fixed width and some with a fluid one.

Margins

Margins have a fixed width. They are the empty space on the left and right side of the window, and they keep text and other content from running to the edge of the display. The margin grows with the window: it is smallest on a phone and largest on a desktop.

Gutters

Gutters have a fixed width. They are the empty space between the columns, and they keep the content of one column apart from the next.

Columns

Columns are fluid. They share the width that is left after the margins and gutters, which is what makes the layout responsive. The number of columns is fixed per breakpoint: 4, 8 or 12.

The fixed values are not new numbers: margins and gutters are steps of the spacing scale, and the breakpoints decide which set applies. All values are listed on the Tokens tab.

This documentation has four tabs. Grid (this page) explains the grid. Breakpoints lists the five ranges and how to write them. Spacing has the spacing scale. Tokens lists every layout token from the package.

Anatomy

The grid of the Desktop breakpoint, drawn to scale from the tokens. The grey areas are margins, the blue areas are columns and the white between the columns is the gutter.

  1. Margin. The fixed space at the left and right edge of the window. It also frames the content area.
  2. Gutter. The fixed space between two columns.
  3. Column. A fluid track. Content is placed on one column or spans several.

Grid by breakpoint

The grid changes at five breakpoints. Each figure below is the grid at one window width, drawn from the tokens at that breakpoint. The window of a phone has 4 columns, a tablet 8 and a desktop 12.

XSmall: 0px to 639px

Below 640px the grid is a 4-column grid (bp-xs). The smallest supported window is 375px. It uses the Mobile base styling.

  • Margin: … site-margin-xs
  • Gutter: … gutter-xs
  • Column: … columns, fluid width

Small: 640px to 768px

From 640px to 768px the grid is an 8-column grid (bp-sm). A tablet still uses the Mobile base styling.

  • Margin: … site-margin-sm
  • Gutter: … gutter-sm
  • Column: … columns, fluid width

Medium: 769px to 1023px

From 769px to 1023px the grid is a 12-column grid (bp-md). This is the first breakpoint with the Desktop base styling.

  • Margin: … site-margin-md
  • Gutter: … gutter-md
  • Column: … columns, fluid width

Large: 1024px to 1280px

From 1024px to 1280px the grid is a 12-column grid (bp-lg), the same as Medium but with a wider margin.

  • Margin: … site-margin-lg
  • Gutter: … gutter-lg
  • Column: … columns, fluid width

XLarge: 1281px and up

From 1281px the grid has the same settings as Large (bp-xl). The margin is infinite: the content area stops growing at 1200px and is centered, so the space on both sides takes up the rest. The figure shows the largest prototype width, 1440px.

  • Margin: … site-margin-xl at 1440px
  • Gutter: … gutter-lg
  • Column: … columns, fluid width

Build with the grid
Write the frame mobile-first with Tailwind (the stack of this project): the margin as padding on the section, and the columns and gutters on a grid inside it. The numbers are the tokens of the breakpoint, see Tokens.
Without Tailwind, use the same tokens in CSS. Write the token with its pixel fallback.
Never write a column width. Columns are fluid: a block spans a number of columns and the grid decides the width.




Usage
Do
  • Build every page on the grid: margin on the section, columns and gutters inside it.
  • Place content on whole columns. A block spans one or more columns.
  • Write mobile-first and add sm:, md:, lg: and xl:.
  • Use the margin and gutter tokens of the breakpoint, not a number that looks right.
Don’t
  • Set a fixed width on a column.
  • Let content run into the margin, or add your own side padding on top of it.
  • Use another number of columns than the breakpoint has (for example 12 on a phone).
  • Make the content area wider than 1200px on large windows.
