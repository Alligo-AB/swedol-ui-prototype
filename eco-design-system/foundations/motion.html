Foundations

Easing and Duration

Interaction is a combination of functionality, intention and connection and are conveyed through the use of motion.

Utilize these fundamental principles, illustrations, and tokens to develop coherent and realistic animations to bring a nice user experience and to help inform our users. The principles and guidelines of motion stated here are highly dependent on its purpose and application. These principles will be more obvious in some cases and may vary in other scenarios, but should be used as best as possible in order to ensure consistency.

General Guidelines

Timing

The duration required for an action to occur is known as timing. It is crucial to consider timing carefully in all animation scenarios.

Spacing

Spacing refers to the gap between two frames of a moving object. Utilizing varied spacing is essential to achieve smooth transitions.

Ease

Ease is affected by both timing and spacing, playing a significant role in how actions flow. Objects should smoothly accelerate and decelerate during movements.

The selection of a easing type depends on how a transition moves in relation to the screen. A rule of thumb regarding the combination of distance and duration in order to mimic real-world physics is:

  • Fast fade, short distance
  • Medium fade, medium distance
  • Slow fade, long distance

Custom properties

    

    

      
Use in CSS

      
/* Drawer slides in */
.drawer { transition: transform var(--duration-medium-3) var(--ease-decelerate-emphasized); }
/* Button hover */
.btn    { transition: background-color var(--duration-fast-4) var(--ease-standard); }
/* Element leaves the screen */
.toast--exit { transition: opacity var(--duration-fast-3) var(--ease-accelerate-generic); }

    

  






  

    
Usage

    

      

        
Do

        
    
          
  • Use decelerate-emphasized to bring things on screen (drawers, menus, notifications).
    • 
          
  • Use standard for hover states.
    • 
          
  • Use accelerate-generic when an element leaves.
    • 
          
  • Match the duration group to the distance.

Don’t

        
    
          
  • Go over 600ms.
    • 
          
  • Use a linear or custom curve when a token fits.
    • 
          
  • Use accelerate-generic for an element that enters.
    •
