Foundations

Layout

The layout is the foundation for all visual elements. It guides creative choices, supports the content and gives every page the same flexible frame: a grid, five breakpoints and one spacing scale.

Five breakpoints decide when the layout and the components change. Learn the ranges, how to write them in code and how to check a page.

GridBreakpointsSpacingTokens

Overview

In responsive design a breakpoint is the window width at which the layout and the content adapt, so that the experience stays good on every screen size.

The responsive grid changes the margins, the width of the content and the number of columns at each breakpoint, and the components change size with it. ECO has five breakpoints, and they are the same for every page and every component.

Breakpoints work together with the grid, and the values of each one are listed on the Tokens tab.

Where your window is

The breakpoint of the window you are reading this in. Resize the window and it follows.

Breakpoints

ECO uses five breakpoints. The grid values are read from the token package.

BreakpointTokenRangeMarginGutterColumnsBase styling

Mobile base styling is used by XSmall and Small. Desktop base styling is used by Medium, Large and XLarge. On XLarge the margin is infinite: the content area is centered and stops at 1200px.

Small is mobile

The Desktop base styling starts at 769px, not at 768px and not at 640px. A tablet (Small, 640px to 768px) has more columns and a wider margin than a phone, but its type and components are the Mobile ones. Never write the desktop style at sm.

Components can have more

A component can change at other widths than these five. For example a section changes its padding at 640, 769, 1024 and 1281px. Such breakpoints are specified with the component.

What changes at Desktop

The breakpoint where the base styling switches is Medium, 769px. These are the main things that change there.

Usage

Write mobile first: the style with no prefix is the phone, and each larger breakpoint adds to it with a min-width query. The queries use the start of each range.

In Tailwind the same five breakpoints are the screens of the config. xs is the default (no prefix).

Check a breakpoint

A page is not done until it has been checked at the breakpoints, with the real values and not by eye.

  • Check at least three widths: XSmall (about 375px), Small (about 700px) and Medium or Large (1024px or more).
  • Read the computed values with getComputedStyle: Small must show the mobile values.
  • Check the 769px edge: 768px is mobile and 769px is desktop.
  • Test the interaction at every breakpoint, not just the look.

Dos and don’ts

Do

  • Write mobile-first: the style with no prefix is XSmall.
  • Switch to the Desktop styling at md (769px).
  • Let a tablet look like mobile, with more columns and a wider margin.
  • Specify extra component breakpoints with the component.

Don’t

  • Switch to the Desktop styling at 640px or 768px.
  • Write a query for one device, for example an iPad.
  • Use max-width queries for the main layout.
  • Make a breakpoint of your own for one page.
