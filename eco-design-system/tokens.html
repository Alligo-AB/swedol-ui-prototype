Design Tokens

Design tokens are the foundational values that define the visual design of the ECO Design System: colors, typography, spacing, borders, shadows and motion. Using the tokens keeps every product consistent, and a change to a token reaches every component that uses it.

Every token from alligo-design-tokens, read live from the CDN this site already loads, plus the motion tokens of this site. Search by name or value, filter by category and copy a token as var(--…).
