Button

A button triggers an action or takes the user to another page. It lets the user make a choice with a single tap. Use a mix of styles on one page to point at the main action and still offer the alternatives.

Every example on this page is the real component. Click, hover and press Tab to try it. Specification: .claude/skills/eco-button/SKILL.md.

Hierarchy

    
A page can show more than one button. Combine styles so one action stands out and the others are quieter. Large, Medium, Small and XSmall are shown on each row.

    

    

    
The inverted variants (Primary, Secondary and Blank) are for dark surfaces. Primary inverted can also sit with Primary on a light background as a button of medium importance.


    
Which variant

    

      
VariantUse it for

      
        
PrimaryThe main call to action in a page, banner or card, such as “Add to cart” or “Next”. Use it sparingly: one primary action per major section. Too many cause confusion.

        
SecondaryA second action next to the primary one, such as “Cancel” or “Back”. Also when a task needs more weight than a Blank button, for example “+ Add address” beside a Blank “Update”.

        
BlankLess prominent actions, alone or paired with a primary button: “Read more” next to “Buy now”. Also sub-tasks where a primary button holds the final action, such as “icon + Update”.

        
DestructiveAn action that removes something or cannot be undone, such as “Delete”. Never as a default action.

        
AccentA brand-colored call to action. Use with care so it stays distinctive.

        
SystemFiltering and navigation, mainly inside filter sections or wherever many buttons are grouped. The light frame and quiet selected state lower the cognitive load. Use aria-pressed for the selected state.

        
InvertedPrimary, Secondary and Blank for a dark surface. They improve accessibility and usability where the normal ones would not have enough contrast.

      


    
With icons

    
An icon can go before the label, after it, or on both sides. An icon-only button is a square the same height as the text button and needs an aria-label. The icon is 24px (20px in XSmall). Icons here are Material Symbols.

    


    
Badge

    
A badge sits in the top right corner and shows that something needs attention, such as items in a cart. It is a number (a count that shows “99+” for anything over 99, so type 150 in the playground and you get 99+) or a dot (something new, no count). It works on a button with a label and on an icon-only button, in every size. Size and position follow the button size and breakpoint (see the table in Anatomy & specs).

    

    
In Small and XSmall the number badge overlaps the end of the label, as in Figma. Prefer an icon-only button when the label is long. The badge is decoration for the eye: put the count in the aria-label and mark the badge aria-hidden="true".


    
System buttons and selected

    
System buttons toggle: click one to select or clear it. Selected has a surface-opacity-black-12 surface and the same quiet frame.

    


    
Combinations

    
Put the more important button first on the left on desktop. The primary button is always the strongest one in the group.

    

  







  

    
States

    
Every state for every variant. Hover and focus are forced on this page with data-state so they show at the same time; in your code they come from :hover and the keyboard focus rule. The buttons are live (the disabled ones do not respond).

Hover: Primary, Destructive and Accent get a surface-opacity-white-20 layer on top of their color, Primary inverted a surface-opacity-black-12 layer. Secondary and Blank get surface-opacity-black-05, the inverted ones surface-opacity-white-20. System hover and System selected hover are the same: a surface-opacity-black-12 surface and a border-hover frame. The focus ring is a 2px border-focus line with a 2px gap, drawn outside the button, so it never moves anything. Disabled: Secondary, Secondary inverted and System keep a frame in border-disabled with no fill; Blank has neither; the others get surface-disabled.

  







  

    
Icon buttons

    
An icon button is a single icon that is also a control, with no label and no frame. It is used where the action is well known from the icon: favourite, edit, show on a map, scan, close. Do not use it where the icon alone would be unclear. Use a tooltip (eco-tooltip) and an aria-label.

Eight icons in Figma. Each has Enabled, Hover, Selected and Selected hover, in Large (24px) and Small (20px). Selected shows the filled icon. The icons on this page are Material Symbols stand-ins for the exact Figma drawings.

Close

    
A 24px box with a 20px icon, for closing a modal, drawer, banner or toast. It has a Blank and a Blank inverted version (dark surfaces). Hover adds a surface. The size is the same on desktop and mobile.

Anatomy & specs

    
A button is a box of a fixed height with the content centred. Inside it the label has its own inset, so the width is the label plus both insets. The diagram shows a Large desktop button at 2× with the label and icons outlined.

    Behavior and accessibility
    
    
    
      
    InputResult
    
      
        
    Click, Enter, SpaceRuns the action. Use <button> for actions and <a class="btn …"> for navigation.
    
        
    Tab / Shift+TabMoves between buttons. The focus ring shows only when body.keyboard-nav is set (on Tab, removed on mousedown and touchstart), the same as the form controls.
    
        
    DisabledUse the disabled attribute. It is not focusable and has no hover. Say why in nearby text when the reason is not obvious.
    
        
    System selectedSet aria-pressed="true". It is a toggle, so it must not be used for page navigation.
    
        
    Icon onlyAdd aria-label, and hide the icon with aria-hidden="true".
    
        
    LabelUppercase through CSS, so write it in sentence case in the HTML. Keep it short and start with a verb.

    Usage
    
    
    Several components look like a button. Choose by what the user is doing.

    starts an action or moves to the next stepButton

    follows a link inside a sentenceeco-inline-link

    Do
    
        
      
          
    • Use one Primary button per major section.
      • 
          
    • Use Secondary for “Cancel” and “Back”, and Blank for the quietest actions.
      • 
          
    • Write short labels that start with a verb.
      • 
          
    • Use the inverted variants on dark surfaces only.
      • 
          
    • Give every icon-only button an aria-label.
      • 
        
    
      
    
      
    
        
    Don’t
    
        
      
          
    • Show several Primary buttons next to each other.
      • 
          
    • Use a button for navigation to another site section when a link fits. Use a link.
      • 
          
    • Use Destructive as the default choice in a dialog.
      • 
          
    • Put an inverted variant on a light surface, or a normal one on a dark surface.
      • 
          
    • Hardcode colors or sizes. Use the tokens and the size classes.
