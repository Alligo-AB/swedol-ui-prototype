Components · Notifications

Inline notification

An inline notification gives feedback right where the user is working: next to a form, a quantity field or a delivery estimate. It stays in the page until the user acts or the state changes. It never disappears by itself.

Tokens, sizes, measurements, states and requirements. Values come from the live token package and from Inline notification.

Behavior

InputResult
Click ×Hides the notification.
PersistenceIt stays until the user acts, the state changes or it is closed. It never auto-hides.
TabThe ×, buttons and link take focus with a visible ring.
Inline linkUnderlined when enabled; on hover the underline goes and the color changes (eco-inline-link, Small).

Accessibility Requirements

TopicRequirement
AnnouncementPut the notification in a region with aria-live="polite" (role="alert" for errors that block progress) so it is announced when it appears (WCAG 4.1.3).
StatusThe icon and the text carry the status, not the color alone (WCAG 1.4.1).
FocusThe ×, buttons and links have a 2px ring, border-focus, on keyboard use (WCAG 2.4.7).
Reduced motionHidden without a transition under prefers-reduced-motion: reduce.
