Action link

An action link is a standalone link for lightweight actions like downloads and “view all” navigation, with a leading icon, a trailing icon or both. It is underlined on hover.

Tokens, sizes, states and requirements. Values come from the live token package and from Figma: Action link.

States

Enabled has no underline: the placement and the icons carry the affordance. This is the reverse of the Inline link, whose underline is what tells it apart from the text it sits next to; an action link stands alone and is never embedded in prose. Hover is a color shift, and the underline appears under the label; the icons are never underlined. There is no Disabled state: hide the row or show plain text (see Usage). Hover is forced on this page; in your code it comes from :hover.

Behavior

InputResult
Click text or iconFollows the link. The whole row is the target.
EnterFollows the focused link.
TabThe 2px focus ring shows on keyboard focus only (body.keyboard-nav).
IconsNever underlined: the underline is on .action-link__label only.
Group of linksStacked (action-link-group--stacked): one column, 8px between the links. Divided (action-link-group--divided): one row, a vertical divider only between two links on the same line, wrapping where the row is full. The author chooses the layout; it does not change with the breakpoint.
DisabledNone. Hide the row or show plain text. If a disabled state must ship: aria-disabled="true", exempt from the contrast minimum but still recognizable.
MarkupA real <a href>. Icons are aria-hidden.

Accessibility Requirements

TopicRequirement
ElementA real <a href>, also for a download (add the download attribute when the file is on the same origin). If an instance triggers a JavaScript action with no navigation, it must be a <button> styled the same way: never fake it with an <a>.
NameThe visible label, extended where needed so it still begins with the visible text (WCAG 2.5.3 Label in Name): “Download product sheet, PDF 2 megabytes”. Both icons are decorative: aria-hidden="true", no alt text (WCAG 2.4.4).
DownloadsAnnounce the file behavior in the accessible name: do not rely on the icon alone.
Target sizeA standalone link needs at least 24×24px (WCAG 2.5.8), and at least 8px between stacked links. The drawn size stays 20px (Small) and 22px (Medium on mobile), but an invisible layer (.action-link::after, at least 24px high) makes the clickable area 24px. Keep at least 8px between stacked links so the areas do not overlap.
FocusA 2px ring around the whole link with border-focus (4.9:1 on white) and 2px offset, on keyboard focus (WCAG 2.4.7, 1.4.11).
ColorThe default state has no underline, so the icons and the placement are the affordance. An action link must therefore never appear inside body copy, where it would rely on color alone (WCAG 1.4.1).
ContrastLabel and icons need at least 4.5:1 in the default and hover states (WCAG 1.4.3). On white: Primary 21:1, Primary hover (#737373) 4.7:1 (4.4:1 on #f6f6f6), Inverted on black 21:1 and Inverted hover about 12:1. Open point: Inverted hover on a mid-gray such as #737373 is 2.8:1. Confirm with design.
