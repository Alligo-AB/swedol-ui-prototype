Compact Icon Button

A compact icon button is a frameless, icon-only button as big as its icon (20px or 24px), for places too small for a regular icon button.

How to add a compact icon button to a page. The file is components/css/icon-button-compact.css.

Examples & GuidelinesSpecificationsCode

Basic Usage

Link the shared file once per page. Never copy the rules into a page.

StepWhat to do
1. Link<link rel="stylesheet" href="/components/css/icon-button-compact.css"> (and icon.css). Both templates already have them.
2. ButtonA button.icon-btn-compact with aria-label and an icon span.
3. ToggleAdd aria-pressed="false" and flip it in your script.

API

Class / attributeUse
icon-btn-compactThe button.
icon--sm / icon--mdOn the icon: 20px or 24px.
icon-btn-compact--fill-hoverThe icon turns solid on hover (favourite).
icon-btn-compact--surface-hoverA surface on hover instead of a grey icon (close). 24px.
icon-btn-compact--invertedOn a dark surface.
icon-btn-compact__off / __onIcon for the enabled and for the selected state.
aria-pressed, .is-onSelected state.
