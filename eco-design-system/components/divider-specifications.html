Divider

A divider is a 1px line that separates content groups, so users can scan and organize information. It is decorative and never interactive.

The line, the tokens and the requirements. Values come from the live token package and from Figma: Divider.

Examples & GuidelinesSpecificationsCode

Design Tokens

Resolved from the live token package.

ColorUseTokenValue

Sizes

VariantThicknessLength
Horizontal1px (height)Fills the container (width: 100%)
Vertical1px (width)Fills the row height (align-self: stretch)

The thickness is a hairline: there is no spacing token for it, and a divider is never thicker. The size does not change with the breakpoint.

Measurements

Dimensions

AttributeValue
Thickness1px
Horizontal lengthThe width of the container
Vertical lengthThe height of the row
Padding and marginNone: the space comes from the parent gap

A divider has no padding or margin of its own, so there is no measurement figure.

Spacing

The space around a divider belongs to the parent. Use a spacing token for the gap.

PartValue
Space above and below a horizontal dividerThe parent gap, a spacing token such as space-16
Space beside a vertical dividerThe parent gap, a spacing token such as space-24

States

A divider has no states: no hover, focus, active or disabled.

Behavior

TopicResult
InputNone. A divider has no hover, focus or click.

Accessibility Requirements

TopicRequirement
SemanticsUse <hr> (or role="separator") when the line separates content for everyone. Use aria-hidden="true" when it is only visual.
VerticalSet role="separator" and aria-orientation="vertical".
ColorNever rely on color alone. If the line carries meaning, the structure (headings, lists) must also show the grouping (WCAG 1.3.1).
ContrastEnsure enough contrast if the line carries meaning (WCAG 1.4.11). Prefer Primary or Tertiary over Secondary.
