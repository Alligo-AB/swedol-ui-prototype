Icons symbolize common actions, features and themes in our products. The set is Material Symbols and custom icons: customized symbols, brand icons for Swedol and Tools, social icons and logos.

Basic Usage

Use the Material Symbols name as text inside a span with the icon class, or an inline SVG for a custom icon. Put aria-hidden on an icon next to a label; otherwise name the control that holds the icon.
