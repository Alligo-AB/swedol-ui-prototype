Icon

Icons symbolize common actions, features and themes in our products. The set is Material Symbols and custom icons: customized symbols, brand icons for Swedol and Tools, social icons and logos.

How to add an icon to a page. The file is components/css/icon.css.

Examples & GuidelinesSpecificationsCodeLibraryAdd an icon

Basic Usage

StepWhat to do
1. FontThe Material Symbols Outlined font (both page templates have it).
2. CSS<link rel="stylesheet" href="/components/css/icon.css">
3. MarkupA span.icon with the Material Symbols name as text, or an inline svg.icon for a custom icon.
4. Size and styleAdd a size class (icon--sm, icon--md …) and icon--fill for the active state.
5. Accessible namearia-hidden="true" next to a label. Otherwise name the control that holds the icon.

Icon

API

ClassUse
iconThe icon. 24px, icon-primary, Outline.
icon--xxs … icon--xlSize: 12, 14, 20, 24 (default), 40, 48.
icon--fillFill style (Material Symbols).
icon--invertedOn a dark surface.
icon--inheritTake the color of the parent, for example inside a button.

Things to know

  • A custom icon has fill="currentColor" and no width or height of its own: the size class sets them.
  • Do not set font-size on a font icon. Use a size class so the optical size follows.
  • The icon library data is components/icon-library/icon-library-data.js, generated by eco-design-system/gen/gen_icon.py data. Do not edit it by hand.
  • The library script is components/js/icon-library.js.
