Pagination

Pagination here is a “load more” pattern: a counter, a thin progress bar and a button that adds more items to a list without a page load.

The tokens, the spacing per breakpoint, the measurements and the requirements. Values come from the live token package and from Figma: Pagination.

Open points

pagination.css writes the gaps (24px, 16px), the 190px width and the counter text (16/22, 17/24 from 769px) as pixels. The values match the spacing scale and the body-md pair, but are not yet written as tokens.

States

The component has no states of its own. The button has the states of the Secondary button. When all items are shown, the button is disabled (Figma Secondary disabled) and the counter and the bar show the full count.

Accessibility Requirements

TopicRequirement
ButtonA native <button> with a specific label (“Show more reviews”). Keyboard: Tab, Enter, Space. Visible focus ring from eco-button.
Status messagePut aria-live="polite" on the counter so the new count is announced without moving focus (WCAG 4.1.3).
Progress barIt repeats the counter, so give it aria-hidden="true". Never rely on the bar alone (WCAG 1.4.1).
FocusA button that becomes disabled loses focus: move focus to the first item that was just loaded (WCAG 2.4.3).
ContrastCounter text is Surface 60 on white. The track (Surface 10) is decoration, the count carries the meaning.
