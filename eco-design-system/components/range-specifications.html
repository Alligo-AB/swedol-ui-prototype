Range

A range lets the user pick one value from an ordered series by dragging a thumb, with the current value shown as text.

Tokens, dimensions, states and requirements. There is no Figma component: values come from the live token package and the specification skill.

Attributes

Attribute on [data-range]Meaning
data-labels="A|B|C"Value text per step, shown right of the label and set as aria-valuetext. Without it the number is shown (plus data-unit).
data-ticks="a|b|c"Tick labels under the track, one per step. Defaults to data-labels. Omit the .form-range__ticks div for none.
data-recommended="1"Step index of the recommended default. Its tick gets a *; explain the * near the control.
data-unit="px"Suffix for numeric ranges without data-labels.

Accessibility Requirements

TopicRequirement
ElementAlways the native <input type="range">, never a div imitation. Keyboard and screen readers then work for free.
LabelA visible label linked with for and id.
ValueTicks are aria-hidden; the value is read through aria-valuetext.
Focus2px ring border-focus on :focus-visible (WCAG 2.4.7, 1.4.11).
Target sizeThe 24px hit area meets WCAG 2.5.8 (24px) but not the 44px recommendation.
DisabledNot focusable. Disabled tokens are exempt from contrast requirements.
