Action link

An action link is a standalone link with an optional icon on the left and a chevron on the right. The text is underlined on hover only.

Every example on this page is the real component, not a picture. Specification: .claude/skills/eco-action-link/SKILL.md. Figma: Action link.

Usage
Pick the link type by where it sits. Read Links guide first.
The link…Use
stands alone, with an optional icon: “View all products”, “Download document”Action link
sits inside a sentenceInline link
is a card or a logo, presented graphicallyTile link
runs an action in the page (save, send, open a modal)eco-button
Do
  • Keep the label short and say where the link goes.
  • Use the chevron to show forward movement; the left icon for the type of action.
  • Use Inverted on dark surfaces only.
  • Use a real <a href>.
Don’t
  • Put an action link inside a paragraph (use Inline link).
  • Underline the icon.
  • Use it as a button for an action that does not navigate.
  • Mix Regular and Bold links in the same group.
