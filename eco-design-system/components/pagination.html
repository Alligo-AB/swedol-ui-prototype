Pagination

Pagination here is a “load more” pattern: a counter, a thin progress bar and a button that adds more items to a list without a page load.

Every example on this page is the real component, not a picture. Specification: .claude/skills/eco-pagination/SKILL.md. Figma: Pagination.

Usage
The list…Use
is long and more items are loaded progressively, total knownPagination (load more)
is already fully shownNothing: hide the component
needs numbered pages (1, 2, 3 …)A different pattern (not built)
Do
  • Place it last in the section or list.
  • Hide the whole component when all items are shown.
  • Compute the bar width from the numbers.
  • Use the Secondary Medium button.
Don’t
  • Add padding below the component.
  • Hide only the button.
  • Stretch it to the section width.
  • Use a Primary button.
