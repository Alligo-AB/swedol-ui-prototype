Pill segment control

A pill segment control switches between two to four related views or filters in the same surface. A pill slides to the active segment.

Tokens, sizes, measurements, states and requirements. Values come from the live token package and from the specification skill: Pill segment control.

States

Hover darkens the track to border-tertiary and underlines the inactive segment. Focus has no style of its own: the buttons use the global keyboard focus ring. Hover is forced on this page.

Width

Fluid (width: 100%) only below 640px, where the segments share the space evenly. From 640px it shrinks to its content (width: auto, align-self: flex-start). Count: two to four short options on one row.

Behavior

TopicRule
Sliding pillThe pill is its own .pill-segment-control__thumb. pill-segment-control.js sets its width and translateX from the active button’s offsetWidth and offsetLeft, because the buttons can have different widths. It re-measures on resize and load.
EventA bubbling segment-change event with detail.button.
Count2–4 short options on one row. More: eco-select or eco-radio.
DisabledNot specified. Pull State=Disabled from Figma before building it.

Accessibility Requirements

TopicRequirement
Markuprole="group" with an aria-label; the buttons carry aria-pressed.
FocusNo own style: the buttons use the global focus ring on keyboard focus (border-focus). Never add a second ring (WCAG 2.4.7).
ColorThe active segment is also shown by the pill, not by color alone.
MotionReduced motion: the pill slide should be turned off. Open point: the CSS does not yet have a prefers-reduced-motion rule.
