Overview

Links take users somewhere: to another page, to another site, to a section of the same page, or to a resource such as a PDF, an email address or a phone number. They are the lightest interactive element in the ECO Design System. Where a Button performs an action, a link always navigates.

The system has three link components: Inline link, Action link and Tile link. They share the same foundation (semantics, keyboard behavior and state logic) and serve different contexts. Choosing the right one comes down to where the link lives and how much visual weight it needs. Read this guide before you build a link.

When to use a link

Use a link when the user should:

  • Go to another page in the site or the application
  • Go to an external site
  • Jump to an element on the same page
  • Open a resource, such as a PDF, an email (mailto:) or a phone number (tel:)

A link navigates; a button acts. For an action in the page (save, send, open a modal) use eco-button.

Modifiers

Every type has a weight (Regular by default, Medium and Bold). The Inline link and the Tile link also have an italic style, so a link can follow the text around it; the Action link is never italic. The Inline link also has a reverse underline (underline on hover only).

Which one

Ask in this order and take the first yes.

  1. Does the element perform an action instead of navigating? Not a link: use eco-button.
  2. Does the link sit inside a sentence, a paragraph or other text? Inline link.
  3. Is it a graphic, prominent surface in a grid or a scroller of peers (a brand, a category, a shortcut)? Tile link.
  4. Does it stand on its own, with an icon? Action link.

Behavior

All three link types share one interaction model: the entire element is the click target, Tab moves focus and Enter activates.

TopicResult
MouseClick anywhere on the link: the text, an icon or the whole tile.
KeyboardTab moves focus and shows the focus ring. Enter activates the link.
MarkupA real <a href> in every case. Links navigate; buttons act.
MotionColor changes over duration-fast-3 with ease-standard.
SizingSizes follow the type scale. A link inside content matches the size of the text around it (Inline link, Large, Medium or Small). A standalone link matches the default body copy size of the page.

Usage

When not to use

Name the destination

The link text says where the link goes, for every type. A vague text does not help the user, and a screen reader reads links out of context.

One type per group

Links that sit together are the same type, so the group reads as one set.

For an action that does not navigate

A link goes somewhere. For an action in the page use eco-button.

Do

  • Choose the type by placement first, prominence second.
  • Name the destination in the link text.
  • Use one type per group of links.
  • Use eco-button for actions that do not navigate.

Don’t

  • Use an inline link outside a sentence.
  • Add an icon to an inline link.
  • Use a tile link for ordinary text navigation.
  • Write “click here” as the link text.
