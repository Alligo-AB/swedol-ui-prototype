Links guide

ECO has three link types: inline link, action link and tile link. Read this guide before you build a link.

Which link type

Use a link when the user should go to another page, to another site, to a spot on the same page, or act on something (open email, call a number). Choose the type by where the link sits and how prominent it must be.

TypeWhereUnderlineIconsPage
Inline linkInside a sentence or text blockOn when enabled, off on hoverNeverInline link
Action linkStandalone, not in body textOff when enabled, on on hoverLeft and/or rightAction link
Tile linkGraphical and prominent, like a card or buttonNoneWith or withoutTile link

Quick decision

  1. Does it run an action in the page (save, send, open a modal)? Use a button, not a link: eco-button.
  2. Is it inside a sentence? Use an inline link.
  3. Is it a logo, a category or a shortcut shown as a card? Use a tile link.
  4. Otherwise it stands alone: use an action link.

Behavior

All three link types behave the same way for input.

InputResult
MouseClick anywhere on the link text or its icon.
KeyboardEnter while the link has focus. Tab shows the focus ring.
MarkupA real <a href> in every case. Links navigate; buttons act.
MotionColor changes over duration-fast-3 with ease-standard.

Usage

Do

  • Choose the type by placement first, prominence second.
  • Name the destination in the link text.
  • Use one type per group of links.
  • Use eco-button for actions that do not navigate.

Don’t

  • Use an inline link outside a sentence.
  • Add an icon to an inline link.
  • Use a tile link for ordinary text navigation.
  • Write “click here” as the link text.
