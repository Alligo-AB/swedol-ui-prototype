List Item

A list item is the content of one row: an optional leading element, a label and an optional trailing element. It is used inside Menu, Overflow menu, List Picker, Drawer link and Filter sections in drawer content.

The row itself (height, padding, divider, hover, focus) belongs to the container. Specification: .claude/skills/eco-list-item/SKILL.md.

Variants

    
Two sizes. Seven leading elements and seven trailing elements combine freely, with a regular label, a bold label or no label, and optional overline and supporting text. Use the Breakpoint toggle to preview Desktop (769px and up) and Mobile (below 769px).

    
Breakpoint
      

    
Leading

    
What comes before the label: nothing, an icon, a check box, a radio button, a color swatch (alone or in a frame) or an image.

    

    
Trailing

    
What comes after: nothing, an icon, a short value in secondary or tertiary text, or a control (check box, radio, switch). A trailing control is presentational: the item or row carries the state. Click an item to toggle it.

    

    
Overline and supporting text

    
One to three lines: an optional overline above the label (small uppercase, tertiary) and optional supporting text below it (body-sm, tertiary, clipped after two lines). The container row needs vertical padding for rows taller than one line.

    

    
Label weight and sizes

    
Regular is the default. Bold marks a heading-like row, often with a secondary value. Small is for compact surfaces.

    

  





  

    
States

    
A list item has no hover or focus of its own: the container row draws them (see Menu). The item reflects selected and disabled. Inside a container the row carries aria-selected / aria-disabled. A standalone item with a check box, radio or switch is itself role="checkbox", "radio" or "switch" with aria-checked: click or Space toggles it. Every item on this page is live, and each sits in a demo row that shows the Menu hover (surface-navigation-hover); the hover belongs to the row, not to the list item.

Anatomy & specs

    
One flex row: leading element, label, then a flexible gap, then the trailing element. Gaps are 8px. The row height comes from the tallest part (image 48px) and the container.

Usage

    
Use a list item to fill a row in a container that already exists. It is not a page element on its own.

    
The user…Use
chooses from a list that opens from a button or a SelectMenu with list items as rows
picks a value in a filter or picker rowList item with a check box, radio or swatch
sees one fixed label and valuePlain text, or a table (eco-table)
reads a long description with actionsNot a list item: use a card or section

    

      
Do
  • Keep the label to one line.
  • Use one leading type per list: do not mix check boxes and icons.
  • Inside a Menu put the state (aria-selected) on the row. A standalone item with a control uses role and aria-checked.
  • Use the trailing value for a short number or text.

      
Don’t
  • Use a list item outside a container (Menu, picker, drawer).
  • Put a real <input> inside an option row: the leading box is presentational.
  • Add hover or divider styles to the list item: the container owns them.
  • Hardcode colors or sizes: use the tokens and size classes.
