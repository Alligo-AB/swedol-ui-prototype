Inline link

An inline link is an underlined text link that flows within body copy, lists and UI text. The underline is its affordance, and it is never paired with icons.

Tokens, sizes, states and requirements. Values come from the live token package and from Figma: Inline link.

Design Tokens

Resolved from the live token package.

ColorPartTokenValue

A link has the same color as the text around it, so the enabled colors are the text colors (Secondary and Tertiary are the same values as text-action-secondary and text-action-tertiary). The hover colors are the three action hover tokens: text-action-primary-hover, text-action-secondary-hover and text-action-tertiary-hover.

Measurements

Dimensions

AttributeValue
HeightThe line height of the text: 32, 28, 24 or 20px (desktop)
Padding and marginNone
UnderlineThe browser’s default 1px underline
IconNever

An inline link has no padding or margin of its own, so there is no measurement figure. It takes its box from the text around it.

States

The reverse of the action link: underlined when enabled, the underline is removed on hover and the color changes. Hover is forced on this page; in your code it comes from :hover.

Breakpoint
StatePrimarySecondaryTertiaryInverted

Enabled is underlined text (Default) or text with no underline (Reverse). Hover is a reduced-contrast text: the color shifts and the underline goes (Default), or the underline appears (Reverse). There is no Disabled state: remove the link or show plain text.

The last two rows are the reverse underline (Figma “Reverse=yes”): no underline when enabled, underline on hover.

Behavior

InputResult

IconsNever. A link with an icon is an Action link.

Accessibility Requirements

TopicRequirement
ElementA real <a href> only. Links navigate; anything else is a <button>. Never href="#" with a JavaScript handler (the documentation examples use it only to keep the page from jumping).
Accessible nameThe visible text. When more context is needed, extend it with an aria-label that begins with the visible text (WCAG 2.5.3 Label in Name), for example the visible “Delivery terms” with aria-label="Delivery terms (PDF)".
New tab or fileA link that opens a new tab or a file says so in its accessible name (“opens in a new tab”), and has rel="noopener".
Target sizeInline links in a text block are exempt from the 24px minimum (WCAG 2.5.8 inline exception). A standalone list of links (a footer list) needs an effective height of at least 24px, from the line height or padding.
NameThe link text names the destination and makes sense out of context (WCAG 2.4.4). Never “click here”.
ColorThe underline separates the link from the text, so color is not the only signal (WCAG 1.4.1).
ContrastText needs at least 4.5:1 against its background in every state, hover included (WCAG 1.4.3). The link color against the surrounding text needs at least 3:1 or a non-color indicator: the underline is that indicator, another reason to keep it. Use Inverted on dark surfaces. Open point: measured on white, Tertiary hover (#939595) is 3.0:1 and fails; Primary hover, Secondary hover and Tertiary (#737373) are 4.7:1 on white but 4.4:1 on #f6f6f6. Confirm with design.
DisabledNever disable a link: a disabled <a> has no standard semantics. Remove it or render plain text.
StyleThe size, line height, letter spacing, weight and italic match the surrounding text. A link is never larger or bolder than its text for emphasis.
FocusA 2px ring with border-focus and 2px offset, on keyboard focus (WCAG 2.4.7, 1.4.11).
