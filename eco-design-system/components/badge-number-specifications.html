Badge Number

A number badge is a round badge with a number or a check mark.

Tokens, sizes and requirements. Values come from the live token package and from Figma: Number.

Dimensions

Horizontal padding of the three sizes with a number, at true size. Window follows the window width; Desktop (769px and up) and Mobile force the breakpoint. The height and width of the circle are in the table.

A badge is round for one digit and wider for more digits (min-width equals the height). Open point: Figma still holds the desktop label size (14/14) and a 20px check mark on Large mobile, in a 20px circle; the mobile badge here uses 12/12 for the number like every other mobile badge, and the 20px check mark as in Figma. Confirm both.
