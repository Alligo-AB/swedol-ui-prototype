Overview
A tag shows an active filter: one value the user has chosen to filter a product list or a search result by. Tags are used for this only.
Tag has two variants (Grey and White), two sizes (Medium and Small) and two states: Remove, the normal state, with a × button that removes the filter, and Default, without ×, for an active filter that cannot be removed from the tag. Only the × is interactive; when it has keyboard focus, the whole tag gets a focus ring.
This documentation has three pages. Examples & Guidelines (this page) shows when and how to use a tag. Specifications holds the values: tokens, sizes, measurements and requirements. Code shows how to add one to a page.




Usage
When to use
Use a tag only to show the active filters above a product list or a search result. Each chosen filter value is one tag, labelled with the category or value name. The × removes that one filter and the list updates at once.
Active filters
  • Place: the row of tags directly above the result list
  • Label: the category or value name only, as in the filter (“Gloves”, not “Category: Gloves”) unless two filters share a value name
  • Order: the order the filters were chosen
  • Clear filters: a link at the end of the row when two or more filters are active
  • Size: Medium; Small in dense places such as a filter drawer
  • Variant: Grey on white, White on a grey surface
  • State: Remove; Default only for a filter that cannot be removed from the tag
When not to use
For categories or labels on content
Tags are not used to show the category of an article or a product. Show that as text or a link.
For a status
A status, a count or a marker such as “New” or “In progress” is a Badge.
For choosing a filter
The user chooses filter values with a Checkbox (or a checkbox tile) in the filter panel. The tag only shows what is chosen.
For an action
A tag does not navigate or submit. Use a Button or a link for an action. The only action on a tag is the ×.
Keep labels short
One or two words, as in the filter. A tag never wraps to a second line.

Do
  • Use tags only for the active filters.
  • Keep the label short: the value name as in the filter.
  • Give the × a label that names the filter: “Remove Gloves”.
  • Use the same size for every tag in a row.
Don’t
  • Use a tag for categories or labels on content.
  • Use a tag as a button or a link, or for a status.
  • Make the whole tag clickable to remove it: only the × removes.
  • Mix Medium and Small in one row.




Anatomy
Tag with Remove
  1. Container. Grey or White surface, sharp corners, no border.
  2. Label. 14/14 Breuer Condensed Bold, normal case, never wraps.
  3. Remove button (optional). A close icon in a real <button>. Only in the Remove state.




Variants
Two variants, each in Default and Remove.
Grey
The default. Use it on white surfaces.
Focus
When the × has keyboard focus, a 2px focus ring is drawn around the whole tag, 2px outside it: the tag is the filter the × removes. A mouse click shows no ring.
White
Use it on grey surfaces, such as Surface Raised Secondary.




Sizes
Medium is the default; Small is for dense places such as a filter drawer. The text is 14px in both. The values are under Sizes in Specifications.




Layout & Appearance
Groups of tags
Put tags in a wrapping flex row with an 8px gap (space-8). The tag is as wide as its label.
Appearance
Sharp corners and no border, like every ECO surface. Grey is a 10% black overlay, so it works on any light surface. Token names and values are under Design Tokens in Specifications.




Behavior
The tag itself is not interactive: no hover and no click. In the Remove state the × is a button; when it has keyboard focus the focus ring is drawn around the whole tag. The ×: a click or Enter/Space removes the tag, and focus moves to the next tag, or to the previous one when it was the last.
Breakpoints
Only the gap between the label and the × changes: 6px below 769px and 8px from 769px (Medium Remove). Everything else is the same on every breakpoint.




Accessibility
All requirements are listed under Accessibility Requirements in Specifications.
Keyboard support
KeyAction
TabMoves focus to the next × button; the focus ring is drawn around its tag. A tag without × is skipped.
Enter / SpaceRemoves the tag.
Screen reader support
The label is plain text. The × has an aria-label that names the tag, for example “Remove Gloves”; the icon is aria-hidden.
