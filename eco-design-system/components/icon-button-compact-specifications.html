Compact Icon Button

A compact icon button is a frameless, icon-only button as big as its icon (20px or 24px), for places too small for a regular icon button.

Sizes, tokens, states and requirements. Values come from the live token package and from Figma: Compact Icon Button.

Sizes

SizeIcon classButton size
Smallicon--sm20 × 20px
Largeicon--md24 × 24px

No padding, border or background. The size is the same on every breakpoint. The click area equals the icon (20px is below the 24px minimum of WCAG 2.5.8; Figma has no larger area, so keep 12px between buttons).

Structure

ElementClassNotes
Buttonicon-btn-compactA <button type="button"> with aria-label. A toggle: add aria-pressed.
Iconicon icon--sm / icon--mdMaterial Symbols (components/css/icon.css), aria-hidden.
Fill on hovericon-btn-compact--fill-hoverFavourite: the outline icon turns solid on hover.
Surface on hovericon-btn-compact--surface-hoverClose: 2px padding (24px), 5% black surface on hover, the icon keeps its colour. Add icon-btn-compact--inverted on a dark surface (white icon, 20% white surface).
Own icon when selectedicon-btn-compact__off + icon-btn-compact__onCompare (custom SVG) and favourite to list (edit): both icons in the button; the second shows when selected.
