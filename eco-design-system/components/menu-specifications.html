Menu

A menu is the list surface that opens from a button or action (Dropdown menu) or from a Select field (Exposed dropdown menu). The two differ only in the element that opens the surface, so they share one component.

Tokens, sizes, measurements, states and requirements. Values come from the live token package and from Figma: Base Item and Menu Item Divider.

Width

The menu is width: 100% of the container the opener gives it.

Behavior

InputResult
HoverRow fill changes. In Multi Select an unselected row previews the check.
Click, Enter, SpaceChooses the row. Select replaces the choice; Multi Select toggles it.
TabRows are focusable. A 2px ring shows inside the row on keyboard focus.
Arrow keysUp and Down move between rows and skip a disabled row.
Disabled rowaria-disabled="true": text-disabled text and icon, no hover fill, not focusable, click and Enter ignored.
EscapeThe opener closes the menu and returns focus to itself.
ScrollingAfter 14 rows the list scrolls.

Open and close behavior belongs to the opener (button or Select field). This page shows the surface only.

Accessibility Requirements

TopicRequirement
Rolesrole="listbox" on the list, role="option" and aria-selected on each row, aria-multiselectable="true" for Multi Select. Name the list with aria-label.
FocusRows are focusable. A 2px ring on keyboard focus (border-focus) (WCAG 2.4.7, 1.4.11).
KeyboardArrow keys, Enter and Space work. Escape closes through the opener.
StateThe check icon is not the only signal: aria-selected carries the state for assistive technology (WCAG 1.4.1).
DisabledA disabled row is aria-disabled and not focusable. Disabled tokens are exempt from contrast requirements.
