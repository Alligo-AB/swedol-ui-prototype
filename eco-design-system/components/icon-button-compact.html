Overview
A compact icon button is a frameless, icon-only button that is as big as its icon: 20px (Small) or 24px (Large). It is for places where the regular icon button (40px, with padding) is too big: a product card, a table row, a field.
It has four states: enabled, hover, selected and selected hover. A toggle such as favourite, compare, favourite to list or edit keeps its selected state with aria-pressed. Size is the same on every breakpoint.
This documentation has three pages. Examples & Guidelines (this page) shows when and how to use a compact icon button. Specifications holds sizes, tokens, states and requirements. Code shows how to add one to a page.




Usage
When to use
  • For an icon-only action on a small surface: compare and favourite on a product card.
  • Inside a field or a list row: clear, edit, location, scan.
  • For a toggle that shows its state by changing the icon: favourite (outline to solid) and compare (arrows to added).

Name it
There is no text, so every compact icon button needs an aria-label, and a tooltip (data-tooltip) so sighted users learn what it does.
Do
  • Give it an aria-label and a tooltip.
  • Use aria-pressed when it is a toggle.
  • Keep 12px between two compact icon buttons in a row.
Don’t
  • Use it for the main action: use a button.
  • Use it when there is room for a regular icon button.
  • Put a background or border in the component: a page may put it on a surface, the component stays frameless.




Variants
Figma has one component set per icon. All have the same sizes and states. The icons are Material Symbols (outline; solid when selected).
Close, with a surface on hover
Close has no selected state. A surface appears on hover instead (icon-btn-compact--surface-hover): the button is 24px, a 20px icon with 2px around it. On a dark surface add icon-btn-compact--inverted.
Toggles
Four buttons keep a selected state with aria-pressed. Favourite and edit turn solid. Compare changes to the custom icon compare_added_custom (arrows with a check). Favourite to list changes to the solid edit icon: first it adds the product to a list, then it edits the list.




Sizes
Small (20px) and Large (24px). The values are under Sizes in Specifications.




States
Hover turns the icon grey. A selected icon is solid. On a favourite, hover also fills the heart, but keeps the colour. Keyboard focus shows the ECO focus ring.

Behavior
  • A toggle flips aria-pressed on click or Space/Enter. The page script does it; the component has no script.
  • The size is the same on every breakpoint.
  • The click area equals the icon. Keep space around it so a finger does not hit its neighbour.




Accessibility

Screen reader support
A native <button> named by aria-label. A toggle is read as pressed or not pressed. The icon is hidden from screen readers.
