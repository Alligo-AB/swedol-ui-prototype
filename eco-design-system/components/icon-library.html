Icon

Icons symbolize common actions, features and themes in our products. The set is Material Symbols and custom icons: customized symbols, brand icons for Swedol and Tools, social icons and logos.

Categories

Icons are grouped in two categories. Choose Custom icons to filter its four groups. Fill icons are not in the library: developers use them for the active state, for example a cart that holds a product.

Material Symbols—Material Symbols in use on the site, Outlined (Fill 0, Weight 300). The Fill style is not listed: it is for developers, as the active state of an icon.
