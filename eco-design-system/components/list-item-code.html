List Item

A list item is the content of one row: an optional leading element, a label and an optional trailing element. It is used inside Menu, Overflow menu, List Picker, Drawer link and Filter sections in drawer content.

How to add a list item to a page. The file is components/css/list-item.css.

Examples & GuidelinesSpecificationsCode

Basic Usage

Link the shared stylesheet once per page. Never copy the rules into a page.

StepWhat to do
1. Link<link rel="stylesheet" href="/components/css/list-item.css">. Both templates already have it.
2. MarkupA div.list-item with a span.list-item__fill (leading element and label) and an optional trailing element.
3. ContainerPut the item inside a container row (li.menu__item). The row sets padding, divider, hover and focus.
4. StateInside a row: aria-selected on the row. Standalone: role and aria-checked on the item, plus the toggle script.
5. SizeLarge is the default. Add list-item--sm for Small.

Things to know

  • Breakpoint: the Large label is 16/22 below 769px and 17/24 from 769px. The CSS does this by itself.
  • Never add height, divider or hover styles to a list item: the container owns them.
  • Swatch colors are product data: set them with style="--swatch: …".
  • The toggle behavior of a standalone item is a small script; copy it from the recipe on this page.
  • The [data-state] selectors do nothing outside the documentation pages.
