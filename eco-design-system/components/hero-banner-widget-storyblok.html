Hero banner

The Hero banner is a versatile component for campaign features and for the headers of landing pages, on campaign pages and sites and on brand pages. It has many settings for building responsive hero sections.

How an editor adds and sets up the Hero Responsive widget in Storyblok. The numbers on the screenshots match the numbers in the headings.

DesignUsageReference and ExamplesStoryblok

Hero widget

The hero banner is available as a widget in the admin tool Storyblok, for the content managers and content creators of our e-commerce sites. In Storyblok the widget is called Hero Responsive (technical name hero responsive).

info

Before you use the tool, read the best practices in Usage.

Start

Start by adding the Hero Responsive widget to the page. In the section, choose Add block and pick Hero Responsive in the Insert block list.

Layout and dimensions

1. Width settings

Two settings control the width and the padding of the component:

  • Fluid width: extends to fill the whole viewport.
  • Regular width: applies responsive padding (top, bottom, left, right) that adapts to the breakpoint.

2. Image guidelines

Recommended image dimensions

  • Regular: 1200×450px. It prevents vertical cropping on the XLarge and Large breakpoints. An image of 1200×450px fits the height of every size without cropping the top and bottom. The left and right sides are cropped as the responsive behaviour starts.
info

Horizontal cropping can happen on Regular banners. For Fluid banners, use extra wide images to avoid unwanted scaling. Remember to add an image description.

  • Fluid: the wider the image, the better. If keeping the proportions matters, an image of 4000×450px keeps the proportions until the viewport is 4001px wide, and it keeps them in every viewport narrower than 4000px. The drawback is the file size, which grows with the image.

The image size does not decrease on small screens. When that matters, for example on a page with many images, make an image for the breakpoint. A jpeg with many colors is larger than one with few.

info

The height of the hero is dynamic. If the content does not fit in the set height of the breakpoint, the hero adjusts to the content. See the heights in Design.

3. Breakpoint visibility

This setting controls what is shown at each of the five breakpoints: XLarge, Large, Medium, Small and XSmall. It makes it possible to adjust the message, the image or the settings for each viewport or device.

Add several Hero Responsive items in the section, to adapt the content for each breakpoint. Then add or remove the visibility items on each hero.

Here the Small and XSmall visibility items are removed.

In this setup the content of the banner is optimised to be shown in the Small and XSmall breakpoints.

4. Content positioning

The placement of the text and the main content is set with two parameters.

4a. Vertical alignment

  • Top
  • Middle
  • Bottom

4b. Horizontal alignment

  • Left: works with any vertical alignment.
  • Center: only with the vertical alignment Middle (a mandatory pairing).

5. Text elements

5a. Text color

Choose Primary or Primary inverted, depending on which color is most readable in the context.

5b. Title size combinations

Title size: choose Large, Medium or Small. The size group affects the pre title, the title and the preamble together.

5c. Pre title

Categorise the content or add context.

5d. Title

The main headline or the campaign message.

5e. Preamble

A longer description of the campaign or the product.

6. Campaign elements

6a. Discount badge

A red badge with the discount amount or a short campaign message.

6b. Campaign price

Shown directly next to the discount badge. Suited to highlight a promotional price.

6c. Old price info

This field appears when the campaign price field is filled in. It shows the price before the discount, under the campaign price.

7. Visual enhancements

7a. Overlay

A gradient overlay makes the text easier to read on an image.

  • The options are several gradient directions.
  • Full covers the whole background.

7b. Overlay opacity

  • The range is 0 (fully transparent) to 100 (fully opaque).
  • Adjust it to balance the visibility of the image and the legibility of the text.

8. Call-to-action buttons

Button One (primary)

  1. Button size. Large, Medium or Small.
  2. Button One text. Write a compelling call to action.
  3. Button One link. A URL path relative to the domain (for example category/category-name), or a full external URL that starts with https://.
  4. Chevron. A toggle that adds a right-pointing chevron for emphasis. See when to use it.
  5. Button overlay. Makes the whole hero clickable, with the link of Button One.

Button Two (secondary)

An optional secondary button with the same settings (text, link and chevron). It appears when the text field is filled in.

9. Branding elements

9a. Brand logo

For brand identity or campaign-specific product logos. Upload the logo as an .svg file. If the background image has many colors or many other branding elements, use only white or black logos if you can, to avoid a cluttered look.

9b. Brand logo position

This setting appears when a logo is added. The logo can sit in three places:

  1. Top right.
  2. Bottom right.
  3. In content*. *Added only for brand pages, when the content is centred with the hero in breakpoint XSmall.

9c. News badge

A toggle that shows a “NEWS!” badge in a circle.

9d. News badge color

  • White
  • Black
  • Green (Swedol only)
  • Red (Tools sites only)

The Swedol and Tools colors are applied automatically for the site in use.

9e. Power Deal logo

Turns on the branding of the Power Deal campaign. The position setting is useful when the content needs the space and the logo should not make the hero use more room, and to reduce clutter.

9f. Power Deal logo position

  • Top Left
  • Top Right
  • Bottom Right

9g. Power Deal border

The switch turns on the graphics of the Power Deal concept. The Swedol and Tools colors are applied automatically for the site in use. Use the border together with the Power Deal logo.
