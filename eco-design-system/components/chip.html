Overview
A chip is a small, interactive element that represents an input, an attribute or an action. Most often it is a filter: the user clicks it to pick a value, and clicks it again to drop it.
Chip has two sizes (Medium and Small), an optional leading icon and four states. A selected chip gets a grey surface and a close icon. On mobile, Medium uses the mobile body text; everything else is the same on every breakpoint.
This documentation has three pages. Examples & Guidelines (this page) shows when and how to use a chip. Specifications holds the values: sizes, tokens, states and requirements. Code shows how to add chips to a page.




Usage
When to use
  • To show the filters or choices the user has picked, for example the values picked in a filter drawer or a dropdown.
  • To show what the user has typed as separate items, for example email addresses in a recipient field.
  • As an action the user can undo, for example a removable chip with a close icon.
When not to use

Filter chips
Filter chips are unselected by default. The user clicks each chip to select as many as they like. Clicking a selected chip, or its close icon, unselects it.
Do
  • Keep the label short: one or two words.
  • Put chips of the same kind in one row (chip-group), so they wrap together.
  • Use the same size for every chip in a row.
Don’t
  • Use a chip as a call to action: use a button.
  • Mix Medium and Small in one row.
  • Use a chip for a status that cannot be clicked: use a badge.




Anatomy
  1. Frame. A 1px Border Primary line. A selected chip has no line and a grey 10% surface instead.
  2. Leading icon. Optional, 16px. It adds meaning to the label.
  3. Label. Body text: body-md on Medium, body-sm on Small.
  4. Close icon. 14px. Shown on a selected chip and on a removable chip.




Variants
Label only
The default chip. The close icon appears when it is selected.
With a leading icon
An icon before the label, for example to show the type of value.
Removable
An input or action chip that always shows the close icon. A click removes the chip (chip--removable).




Sizes
Medium (32px, default) and Small (24px). The values are under Sizes in Specifications.




States
Four states. Hover darkens the frame; a selected chip has a grey surface and a close icon; hover on a selected chip adds a grey frame. Keyboard focus shows the ECO focus ring.
Medium
Small




Behavior
  • A filter chip is a toggle button. A click or Space/Enter selects it or unselects it.
  • A removable chip is removed by a click. Move the focus to the next chip, or to the field, after it is removed.
  • Chips in a row wrap to the next line; they never scroll sideways.
Breakpoints
The size is the same on every breakpoint. Medium uses body-md, which is 16px on mobile and 17px from 769px.




Accessibility
All requirements are listed under Accessibility Requirements in Specifications.
Keyboard support
KeyAction
TabMoves the focus to the next chip.
Space, EnterSelects or unselects a filter chip; removes a removable chip.
Screen reader support
A filter chip is a <button> with aria-pressed, so it is read as a toggle button, pressed or not pressed. A removable chip gets aria-label="Remove …". The icons are hidden from screen readers.
