Inline notification

An inline notification gives feedback right where the user is working: next to a form, a quantity field or a delivery estimate. It stays in the page until the user acts or the state changes. It never disappears by itself.

The buttons in In action show the statuses appearing in context. Specification: .claude/skills/eco-inline-notification/SKILL.md.

In action

    
Two real situations. The notification appears where the work is, replaces the previous one, and stays until the user fixes the problem or closes it.

    
Change password (form feedback)

    
Each button submits the form with a different result. The notification replaces the previous one and stays until it is closed.

    

      

    
Quantity (product information)

    
Informational Weak with its own icon. The message follows the quantity.

    

      

  






  

    
Variants

    
Two sizes, two emphasis levels and two layouts. Pick the size by how much room the message has, and the emphasis by how loud it should be.

    
Large

    
48px high with a 24px icon. The default for messages next to forms and content blocks.

    

    
Small

    
32px high with a 20px icon, for tight spaces such as next to a field. No Actionable layout. Weak exists only for Informational and Warning.

    

    
Actionable

    
Large only. Buttons under the text, indented 32px so they line up with it. Use it when the user can fix the problem from here.

    

    
Actionable with inline links

    
The action area holds either buttons or inline links, not both. Links suit lighter next steps.

    

    
Informational with your own icon

    
Informational Weak is white with a blue edge. Like any Informational notification it may carry an icon the author chooses instead of the default info: a Google Material Symbols name, shown as Outlined (Fill 0, Weight 300, Grade 0). Success, Warning and Error always keep their own filled icon.

    

  






  

    
States

    
Every status in both emphases. Combinations Figma does not define are marked. An inline notification has no hover or focus state of its own; its × and links do.

Usage

    
Inline is for status that belongs to a place on the page and has to stay.

    
The message…Use

    

      
Do
  • Place it next to the thing it is about.
  • Give an Error a way to fix it, in the text or as an action.
  • Use Informational for helper messages such as stock or delivery.
  • Announce it with aria-live when it appears after an action.

      
Don’t
  • Use it for a single field. Use the field’s own error message.
  • Use it for a brief confirmation. Use a Toast.
  • Add the Actionable layout to Small.
  • Use the Weaker emphasis. That is Banner only.
