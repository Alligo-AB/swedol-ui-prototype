Collapsible

A collapsible is a row that opens and closes to show more content, used for FAQ lists and filters. The header can carry a descriptive text, icons, a toggle switch and a number badge. The content animates open.

Tokens, sizes, measurements, states and requirements. Values come from the live token package and from Figma: Base / Collapsible.

Opening is a state change on the spot, so it uses standard easing and a short duration (eco-motion). With prefers-reduced-motion: reduce every transition is off. Compare other values in the live Motion section on Examples & Guidelines.

Behavior

InputResult
Click the header, Enter or SpacetoggleCollapsible(this) toggles .collapsible-wrap--open, sets aria-expanded and sets max-height to the content’s scrollHeight. CSS cannot animate to auto.
Click the toggle switchChanges the switch only. A click on a link or on an element with data-collapsible-ignore in the header does the same.
HoverTitle, text and icons change color.
DisabledNo hover, no click, no Tab.
Several rowsIndependent: opening one does not close another.
BreakpointLarge changes size at 769px.
Window resize while openOpen point. The height is set once, when the row opens. If the text wraps differently after a resize, the height is not updated.

Accessibility Requirements

TopicRequirement
Header elementUse a button, so it is reached with Tab and works with Enter and Space (WCAG 2.1.1, 4.1.2). Older pages still use a div with onclick: it cannot take focus.
StateSet aria-expanded on the header; the script keeps it in sync. Link it to the content with aria-controls.
Switch in the headerA button cannot hold another control. A row with a toggle switch uses a div and has no chevron, or the switch moves out of the header. Open point: Figma shows a switch and a chevron together.
FocusA 2px ring on keyboard focus (border-focus), 2px outside the header.
ContentClosed content is visibility: hidden, so it is not read and cannot be focused.
ContrastThe disabled text color is exempt (WCAG 1.4.3). Helper text and counts use text-tertiary (4.5:1 on white).
MotionReduced motion: all transitions are off.
