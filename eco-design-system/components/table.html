Table

A table shows rows of comparable data. It sits in a wrap with the elevation of a dashboard card and scrolls sideways when the window is narrow.

Every example on this page is the real component, not a picture. Specification: .claude/skills/eco-table/SKILL.md.

Open points: the values come from the docs pages, not from a Figma component. Not built yet: sorting, selection, sticky header, empty and loading states, dark mode, very long cell text, and rows with a control other than a checkbox. The 11px padding is a consequence of the 1px row line.

Do
  • Use th with scope.
  • Keep one header tone per page.
  • Bold the first column as the row header.
  • Check that the wrap scrolls at 375px.
Don’t
  • Use a table for layout.
  • Add a bottom line on the last row.
  • Mix header tones in one table.
  • Hardcode colors, shadow or spacing.
