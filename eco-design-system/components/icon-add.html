Icon

Icons symbolize common actions, features and themes in our products. The set is Material Symbols and custom icons: customized symbols, brand icons for Swedol and Tools, social icons and logos.

Step 1: Find an icon

Material Symbols consolidates over 2,500 glyphs in a single font file with a wide range of design variants.

Get started by finding the icon on the Google Fonts icon site or in the Figma app. Check the Library first: the icon may already exist.

If your needs are not met by Material Symbols, reach out to the Design Systems team about custom solutions.

Step 2: Add the icon to our Figma kit

All of our icons are stored in our ALLIGO ECO Design System Figma file, in the section “Icons”. Designers with edit access in our Figma account can add and edit icons.

To add a new icon to the library, follow these steps:

  1. Import the icon with the customization settings. Material Symbols Outlined: Fill 0, Weight 300, Grade 0, optical sizes 20, 24, 40 and 48; additional sizes 12 and 14. Material Symbols Fill: Fill 1, Weight 300, Grade 0, optical sizes 20, 24, 40 and 48.
  2. Create a component. Add the four size variants of the icon. Convert the icon’s frame to a component: select the frame and press the “Create Component” button (⌥ + ⌘ + K). Look at the other icons in the file for a reference.

Naming icons

  • Use an underscore “_” as the delimiter between words.
  • Use lowercase rather than UPPERCASE, camelCase or PascalCase.
  • Use the generic Material Symbols names that come with the icon, for example icon_name.
  • If it is a customized Material Symbol, or an icon in the style of Material Symbols, add custom, for example icon_name_custom.
  • Use specific names for logo, brand-specific and feature-specific icons that do not come from Material Symbols (for example _logo, _brand, _social), for example name_of_logo_logo.

The full naming rules are in Specifications.

Step 3: Add the icon to the library page

Proposed step, not in the Figma instructions. The library page reads one data file, so a new icon has to be added to it.

  1. Material Symbols icon. Add the Figma name to eco-design-system/gen/icons-material.txt under [outline] or [fill].
  2. Custom icon. Export the 24px variant as SVG. Add one line to eco-design-system/gen/icons-custom.txt: name|group|viewBox|svg content (group: custom, brand, social or logo; fill colors as currentColor).
  3. Rebuild. Run python3 gen_icon.py data in eco-design-system/gen. Never edit icon-library-data.js by hand.
