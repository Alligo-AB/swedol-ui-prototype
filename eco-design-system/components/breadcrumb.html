Breadcrumb

A breadcrumb shows where the page sits in the site and lets the user go back up in one click. Every crumb is a bordered box.

Every example on this page is the real component, not a picture. Specification: .claude/skills/eco-breadcrumb/SKILL.md. Figma: Design, Responsive behavior.

Behavior and accessibility
TopicRule
PlacementDirectly under the header, first in .page, before the title block. The block that follows zeroes its top padding.
Markupnav[aria-label="Breadcrumb"]. Links are <a href>; the last crumb is a span with aria-current="page".
SeparatorA “/” character, never an icon. 4px wide.
TabFocus ring on keyboard focus only.

Usage
SituationUse
The page is more than one step below Home (category, product, landing page)Breadcrumb
Home, or a page directly under Home with no level betweenNone
Tabs or a clear back link already do the jobNone: avoid two
Do
  • Put it first in the page, right under the header.
  • Make every crumb but the last a real link.
  • Set aria-label and aria-current.
  • Let the next block zero its top padding.
Don’t
  • Underline crumbs in the enabled state.
  • Use chevrons or icons between crumbs.
  • Make the current page a link.
  • Hardcode the side padding.
