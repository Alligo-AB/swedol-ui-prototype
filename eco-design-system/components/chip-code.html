Chip

A chip is a small, interactive element that represents an input, an attribute or an action, most often a filter the user can select and unselect.

How to add chips to a page. The files are components/css/chip.css and components/js/chip.js.

Examples & GuidelinesSpecificationsCode

Basic Usage

Link the shared files once per page. Never copy the rules into a page.

StepWhat to do
1. Link<link rel="stylesheet" href="/components/css/chip.css"> and <script src="/components/js/chip.js" defer></script>. Both templates already have them.
2. RowPut the chips in a div.chip-group.
3. ChipA button.chip with aria-pressed="false", a label span and a close icon span.
4. ListenReact to chip:change (filter) or chip:remove (removable).

API

Class / eventUse
chipMedium chip.
chip--smSmall chip.
chip--removableClose icon always shown; click fires chip:remove.
chip-groupWrapping row with 8px gap.
chip:changeFired on a filter chip after a click; event.detail.selected.
chip:removeFired on a removable chip; remove it and move the focus.
