Overview
A divider is a 1px line that separates content groups, so users can scan and organize information. It is decorative: it carries no content and no interaction.
Divider has two directions (horizontal and vertical) and three colors. It has no states and no size, and it looks the same on every breakpoint. The line fills its container, and the space around it comes from the parent gap.
This documentation has three pages. Examples & Guidelines (this page) shows when and how to use a divider. Specifications holds the values: the line, the tokens and the requirements. Code shows how to add one to a page.




Usage
When to use
Add a divider only when spacing alone does not separate the content. Use it to:
  • Separate distinct content groups in a page or a container
  • Organize the rows of a list or a settings page
  • Create hierarchy where content lacks a clear separation
  • Separate form sections or interactive items, such as menu items
When not to use
When whitespace is enough
Every line adds visual clutter. If the content is already grouped by space, a heading or a label, leave the line out.
For a boundary between page sections
A full-width boundary between two page sections is not a divider. Use .page-divider from eco-section: it adds the page margin and padding around the same 1px line.
Keep the space on the parent
Set the space above and below the line with the gap of the parent. A margin on the divider itself makes the space depend on where the divider is used.

Do
  • Separate distinct groups when whitespace is not enough.
  • Create hierarchy between types of information.
  • Set the space around it from the parent gap.
  • Use Primary by default and Tertiary for short side-by-side items.
Don’t
  • Overuse dividers: they create visual clutter.
  • Add a line only for decoration.
  • Use a divider where a heading or label is clearer.
  • Add margin to the divider itself.




Anatomy
Divider
  1. Line. One 1px line in a border color. A horizontal divider is as wide as its container; a vertical one is as high as its row.
A divider has no label, no icon and no padding of its own. The space around it belongs to the parent.




Variants
Two directions in three colors, six in all. A divider has no states.
Horizontal
Between sections, list rows or form groups. It fills the width of its container.
Vertical
Between items placed side by side. Put it in a flex row; it stretches to the height of the row.
In a list
The space between the text and the line comes from the parent gap.




Sizes
A divider has no sizes. The line is always 1px thick, and there is no spacing token for a hairline. The length is set by the container: the full width for a horizontal divider, the full height of the row for a vertical one. Figma shows 335px and 112px as example lengths, not fixed values. The values are under Sizes in Specifications.




Layout & Appearance
Alignment
A horizontal divider starts at the left edge of its container and runs to the right edge. A vertical one sits between two items in a flex row and takes the height of the row.
Appearance
Primary is the default. Secondary is less prominent and has very low contrast, so use it on white only. Tertiary is more prominent and suits short separations, such as values placed side by side. Token names and values are under Design Tokens in Specifications.




Behavior
A divider is not interactive. It has no hover, focus or disabled state, it cannot be tabbed to, and it does not move or animate.
Breakpoints
It is the same on every breakpoint. There is no mobile or desktop value.




Accessibility
All requirements are listed under Accessibility Requirements in Specifications.
Keyboard support
None. A divider is not focusable.
Screen reader support
An <hr> is announced as a separator, so use it when the line separates content for everyone. A line that is only visual, inside a component, gets aria-hidden="true".
