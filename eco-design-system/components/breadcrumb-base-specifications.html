Breadcrumb Base

A breadcrumb base is one level of a breadcrumb trail: a bordered box with a label. A parent level is a link; the current page is bold and not clickable.

Tokens, sizes, measurements, states and requirements. Values come from the live token package and from Figma: Breadcrumb Base.

Width

A crumb is as wide as its label plus the side padding. The label never wraps (white-space: nowrap).

Accessibility Requirements

TopicRequirement
LinksEvery parent crumb is an <a href>. Figma draws the hover crumb as a button; in code it is a link, because it navigates.
Current pageA span with aria-current="page", not a link.
ContrastText in text-tertiary on white and on grey must reach 4.5:1 (WCAG 1.4.3). The border (border-action-3) is decoration, not the only cue.
Target sizeThe box is 34px high on desktop and 26px on mobile. Keep the gap to the next crumb at 8px or more (WCAG 2.5.8).
FocusA visible focus ring on every link (WCAG 2.4.7).
