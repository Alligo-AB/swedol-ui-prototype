Badge

A badge is a read-only status or label: “New”, a count, a discount. It is never clickable.

Every example is the real component, not a picture. Figma: Guidelines.

Overview

Badges and tags are visually similar, but tags are interactive and badges are not.

Badge. A badge indicates a status or a count. Badges are read-only status indicators or labels and are not interactive. They can be placed next to, for example, text links.

Tag (TBA). Use tags to let users group, sort or filter information. Tags often hold keywords or metadata and give quick access to categories.

Badge has five types, one set of pages for each. All types come in a desktop and a mobile version.

Usage

When to use

Use a badge to indicate status, item count, items that need attention, or featured content. A badge must not rely on color alone to carry its meaning: color is not a universal experience.

Combine several elements in one badge (text, emphasis and an icon) to make the meaning easier to see.

Featured or highlighted content

Use a badge to emphasize a product feature or item. Think about badge color, placement and emphasis when it sits near buttons.

Attention and awareness

Urgent communication

Use a badge with an icon and a short label for items that need an action or immediate attention.

Indication

Use a dot as an indicator to draw attention to an icon or a text link when a status has changed. Dots are not for critical alerts and not for standalone use.

Do

  • Keep labels short: one or two words.
  • Use the same color for the same meaning everywhere.
  • Pair an alert color with its icon or clear text.
  • Use Medium or Large on mobile.

Don’t

  • Make a badge clickable.
  • Use color only to say “error” or “success”.
  • Stack dots or put them close together.
  • Use the e-commerce badges outside e-commerce.

Color

Alert

Badge Basic comes in four alert colors. Each color is paired with an icon, so the meaning does not depend on color alone.

ColorExampleMeaningIcon
Informative (default)infoInformativeInformative messages. Default color, the most flexible one.info
Successcheck_circleSuccessPositive feedback or success.check_circle
ErrorerrorErrorNegative feedback or an error.error
WarningwarningWarningThe user needs to take notice.warning

Use an icon only with its own alert color: each icon has an established meaning. Any other icon from the icon gallery may be used where the guidelines do not forbid it.

Neutral

Neutral badges are best paired with alert colors to create contrast through emphasis. For example, an informative badge with strong emphasis next to a neutral badge with weak or weaker emphasis. Use neutral for information that is not an alert.

Emphasis

Use color emphasis to reinforce how important or visible a badge is. Without icons, mix emphasis to tell badges apart, so you do not rely on color alone.

EmphasisExampleWhat it is
StrongStrongDarker background.
WeakWeakA medium, more saturated background.
WeakerWeakerA light background.

Do not mix emphasis without a reason. Do it only where it helps users understand, for example a high and a low emphasis badge side by side to tell two text-only badges apart.
