Badge

A badge is a read-only status or label: “New”, “Archive”, a role name. It is never clickable.

Every example on this page is the real component, not a picture. Specification: .claude/skills/eco-badge/SKILL.md. Figma: Guidelines, All variants.

Sizes
Large and Medium on every breakpoint. Small on desktop only.
With an icon
Use the alert icon with the alert states, so color is never the only carrier of meaning. The icon is 14px with a 4px gap.
Letter case
Sentence case (weight 500) for statuses. Upper case (weight 600) for fixed categories, where the extra weight helps. It is a choice, not a fix.


Color meanings
Badge has no fixed rulebook for colors, but keep the meaning the same across a project. This is the recommended mapping for lifecycle labels.

Do
  • Keep labels short: one or two words.
  • Use the same color for the same meaning everywhere.
  • Pair an alert color with its icon or clear text.
  • Use Medium or Large on mobile.
Don’t
  • Make a badge clickable.
  • Use color only to say “error” or “success”.
  • Use Small on mobile (it is hidden).
  • Use Neutral dark unless you need the weight.
