Checkbox

A checkbox lets the user turn one or more options on or off, independently of each other. The choice is saved when the form is submitted.

How to add a checkbox to a page. The file is components/css/checkbox.css.

Examples & GuidelinesSpecificationsCode

Basic Usage

Link the shared stylesheet once per page. Never copy the rules, and never write a parallel version of the checkbox.

StepWhat to do
1. Link<link rel="stylesheet" href="/components/css/checkbox.css">. Both templates (template.html, mypages/mypages-template.html) already have it.
2. MarkupA <label class="form-checkbox-item"> around an <input type="checkbox"> and a <span> with the label text.
3. Dark surfaceAdd form-checkbox-item--dark on surface-100 or surface-80. Never the light markup on a dark surface.
4. MixedSet input.indeterminate = true in JavaScript. It cannot be set in HTML.

Checkbox

Copy the markup you need. Hover and focus come from :hover and :focus-visible; the [data-state] selectors in the CSS exist only so the documentation can force a state.

Tiles

Tiles have no visible label, so aria-label is required. Several can be chosen with checkbox; on a product page where only one can be chosen, use radio with the same markup.

Things to know

  • The box is the native input with appearance: none. The checkmark and dash are SVG data URIs, so no image file is loaded.
  • A label that contains an input is enough: no for/id pair is needed.
  • Breakpoint: the Large label is 16/22 below 769px and 17/24 from 769px. The CSS does this by itself.
  • The [data-state="hover"] and [data-state="focus"] selectors do nothing outside the documentation pages.
  • A checkbox does not submit when it is unchecked: handle that on the server if a value is needed.
