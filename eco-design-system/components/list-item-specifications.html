List Item

A list item is the content of one row: an optional leading element, a label and an optional trailing element. It is used inside Menu, Overflow menu, List Picker, Drawer link and Filter sections in drawer content.

Tokens, sizes, states and requirements. Values come from the live token package and from Figma: Base List Item.

A list item has no padding of its own, so there is no measurement figure. The row padding belongs to the container (a Menu row has 16px on each side).

States

A list item has no hover or focus of its own: the container row draws them. The item reflects selected and disabled. Every item here is live and sits in a demo row that shows the Menu hover (surface-navigation-hover); the hover belongs to the row, not to the list item.

Width

The item is width: 100% of its container.

Behavior

InputResult
Click, Space, EnterOn a standalone item: toggles aria-checked. A radio only selects and clears the others in its radiogroup.
Arrow keysIn a radio group: move to the next or previous radio and select it (wraps).
TabOne tab stop per item. In a radio group the checked radio is the tab stop.
Disabledaria-disabled="true" and tabindex="-1": clicks and keys are ignored.
Inside a MenuThe row handles clicks, keys, hover and focus.

Accessibility Requirements

TopicRequirement
RoleA standalone item with a control is role="checkbox", "radio" or "switch" (switch wins over check, check over radio) with aria-checked.
StateInside a container: aria-selected and aria-disabled on the row. The visual (check, dot, frame, switch) must match the attribute (WCAG 4.1.2).
Presentational partsThe check box, radio, swatch and switch are aria-hidden. Never put a real <input> inside an option row.
FocusA 2px ring with border-focus, offset 2px, on a standalone item (WCAG 2.4.7, 1.4.11).
ColorThe state is not shown by color alone: the check, the dot or the thumb position changes too (WCAG 1.4.1).
DisabledNot focusable. Disabled tokens are exempt from contrast requirements.
