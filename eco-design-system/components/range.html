Range

A range lets the user pick one value from an ordered series by dragging a thumb, with the current value shown as text.

Every example on this page is the real component, not a picture. Specification: .claude/skills/eco-range/SKILL.md.

Playground

A native range input with a label, the current value and tick labels. Drag, click the track or use the arrow keys. Hover and focus are live (they cannot be forced on a native slider thumb).

Attributes
Attribute on [data-range]Meaning
data-labels="A|B|C"Value text per step, shown right of the label and set as aria-valuetext. Without it the number is shown (plus data-unit).
data-ticks="a|b|c"Tick labels under the track, one per step. Defaults to data-labels. Omit the .form-range__ticks div for none.
data-recommended="1"Step index of the recommended default. Its tick gets a *; explain the * near the control.
data-unit="px"Suffix for numeric ranges without data-labels.

Do
  • Keep to about 4–12 steps in a 480px control.
  • Show the current value as text.
  • Mark the recommended step and explain the *.
  • Link range.css and range.js.
Don’t
  • Build a slider from divs.
  • Use it for two or three options.
  • Use it for exact numbers.
  • Let tick labels collide: use fewer via data-ticks.
