Select

A select lets the user choose one option from a list. It looks and behaves like an input field, with a dropdown arrow. It opens the ECO Menu as its list.

Tokens, sizes, measurements, states and requirements. Values come from the live token package and from Figma: Base Input.

Types

There is one type. The Menu size follows the field: Large opens a Large menu, Small and XSmall open a Small menu.

Width

The field fills its container. The menu is as wide as the field.

The menu opens downwards, or upwards when it has flipped; the 8px move follows that direction. Under prefers-reduced-motion it opens and closes instantly.

Behavior

InputResult
ClickOpens the Menu under the field (no ring on mouse) and the arrow turns 180° clockwise; it turns back when the menu closes. Click a row to choose; click outside to close.
TabThe blue ring shows on keyboard focus only (body.keyboard-nav).
Enter, Space, Arrow keysOpen the Menu on the chosen row. Up and Down, Home and End move; Enter or Space choose; Escape closes and returns focus to the field; Tab closes.
PlaceholderA first option with value="" (disabled, hidden) shows the placeholder in text-tertiary.
Menu positionUnder the field. It flips upwards when it does not fit below and there is more room above; otherwise its height is capped and it scrolls.
DisabledNot focusable. Grey fill, light border, text-disabled text and arrow.

Accessibility Requirements

TopicRequirement
LabelAlways a label with for and id. A placeholder is never the label.
ErrorSet aria-invalid="true" and point aria-describedby at the message.
ListThe Menu is a listbox of option rows, with aria-selected, named by the label. The select gets aria-expanded while it is open.
FocusA 2px ring on keyboard focus (border-focus), not on mouse click (WCAG 2.4.7, 1.4.11). Escape returns focus to the field.
ColorError and success are not shown by color alone: the message says it, and the error message has an icon.
DisabledNot focusable. Disabled tokens are exempt from contrast requirements.
