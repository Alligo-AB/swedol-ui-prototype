Button group

A button group is a row of joined System buttons for choosing between two to four short options. The selected button has a black 12% fill.

Tokens, sizes, measurements, states and requirements. Values come from the live token package and from the specification skill: no Figma component is linked.

The tablet range (640 to 768px) uses the mobile values. The 1px frame is drawn inside each button (inset box-shadow) and shared between neighbours with margin-left: -1px. The group is inline-flex and never wider than its parent.

States

Selected is a black 12% fill (aria-pressed="true"). Hover darkens the frame and, when not selected, adds the fill. Hover and focus are forced on this page; in your code they come from :hover and the keyboard focus rule.

Width

The group is as wide as its buttons and never wider than its parent. It never wraps. Two to four options.

Behavior

TopicRule
SelectionOne selected at a time, set by your script via aria-pressed. The CSS does not toggle it.
Markuprole="group" with aria-label or aria-labelledby; real <button type="button">.
TabEach button is focusable; 2px focus ring with a 2px gap on keyboard focus.
Not navigationA System button group toggles state. Page navigation uses links.
CountTwo to four options. More: a select. When the group is wider than its container, show a select with the same options and keep the two in sync; never shrink, wrap or scroll the group.

Accessibility Requirements

TopicRequirement
Markuprole="group" with an accessible name; real buttons with aria-pressed.
Focus2px ring border-focus with a 2px gap, on keyboard use (WCAG 2.4.7, 1.4.11). It is set with body.keyboard-nav.
StateThe selected button differs by its fill and by aria-pressed, not by color alone (WCAG 1.4.1).
DisabledNot focusable. Disabled tokens are exempt from contrast requirements.
