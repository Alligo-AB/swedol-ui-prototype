Inline link

An inline link sits inside a sentence. It is underlined when enabled; on hover the underline goes and the color changes. It never has an icon.

Every example on this page is the real component, not a picture. Specification: .claude/skills/eco-inline-link/SKILL.md. Figma: Inline link.

Usage
The link…Use
is inside a sentence or text blockInline link
stands alone, optionally with an iconAction link
is a card or a logoTile link
Do
  • Link the words that name the destination (“product page”), not “click here”.
  • Use Primary unless the surrounding text is tertiary.
  • Use Inverted on dark surfaces only.
  • Keep the underline in the enabled state.
Don’t
  • Add an icon to an inline link.
  • Remove the underline in the enabled state.
  • Use an inline link on its own line (use Action link).
  • Link whole sentences.
