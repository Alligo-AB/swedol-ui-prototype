Overview
An inline link is an underlined text link that flows within body copy, lists and UI text. The underline is its affordance: it is underlined when enabled, and on hover the underline goes and the color changes. It is never paired with icons.
It inherits the typography of the text around it and shows that it can be used through the underline and the state changes. That makes it the default way to link from running text, footers, legal copy and helper text.
Inline link has four sizes (XLarge, Large, Medium and Small), four colors (Primary, Secondary, Tertiary and Inverted), three weights (Regular, Medium and Bold), an italic style and a reverse underline (underlined on hover only). It is one of three link types: see the Links guide for how to choose.
This documentation has three pages. Examples & Guidelines (this page) shows when and how to use an inline link. Specifications holds the values: tokens, sizes, states and requirements. Code shows how to add one to a page.




Usage
When to use
Use an inline link when a word or a phrase in body copy, a list or UI text should take the user somewhere or do something. Use it to:
  • Link from within body copy, product descriptions or help text
  • Give secondary navigation in footers, in text next to a breadcrumb or in legal copy (“Read more about our delivery terms”)
  • Link a single item in a list, such as related articles or policy documents
  • Jump to an element on the same page: anchor links, such as the entries of a table of contents
  • Link an email address or a phone number in copy (mailto:, tel:)
  • Go to another page in the site or to an external site
One line: an underlined text element that navigates to a destination while flowing inline with the surrounding content.
When not to use
Keep it inside the sentence
An inline link on its own line is a standalone link. For that use an Action link instead.
For the primary action on the surface
When the link is the main call to action, use a eco-button (or a link styled as a button).
For destinations that are equal peers
Destinations that stand side by side in a grid or a scroller are Tile links.
For an action on the current page
A link always navigates. Expanding a section, opening a modal or revealing more text is not navigation: use a eco-button, or the component that owns the pattern, for example a Collapsible for expanding in place and a Modal for an overlay.
For an icon-only trigger
A link has no icon. An icon-only trigger is an icon button (eco-button, Icon button), and a link that needs an icon is an Action link.
Open new tabs only when needed
Do not open a new tab by default. When a link must (target="_blank", for example a PDF), say so in the link or next to it, and add rel="noopener".
Give the link the style of the text around it
An inline link has the same style as its surrounding text: size, line height, letter spacing, weight and italic, on desktop and on mobile. It is not a way to emphasize a word: never make a link larger or bolder than its text. The Medium, Bold and Italic modifiers exist so a link can follow text that has that style.
Do not disable a link
Avoid disabled links entirely. Remove the link, or show plain text instead. A disabled <a> has no standard semantics, so an inline link has no disabled state.
Writing link text
The link text describes the destination and makes sense out of context: screen reader users often move through the list of links on a page. In the examples the real inline link (Small) shows exactly which words carry the link. The links go nowhere on this page. The examples are in English; on a Swedish page follow the same rules in the Swedish copy around the link.
Link the meaningful phrase
The link text tells users where the link goes and what they get if they click, also when it is read out of context by a screen reader. Link the words that carry the meaning, such as “read our workwear size guide”. Do not link filler words such as “click here” or “more info” alone.
Weave the link into the sentence
When a link sits in a sentence, the linked words read as part of the sentence. Never add “here” at the end as the link.
Use sentence case, except for names and titles
Use sentence case that matches the copy around the link, with no trailing punctuation inside the link. If the link points to a specific page, screen or feature, mirror how that destination is capitalized: “Order History” if that is the real name of the page.
Never paste a raw URL as the link text
A raw address is hard to read and scan and says nothing about the destination. Describe the page.
Keep it short
Use the fewest words that make the destination obvious, typically one to five. A link is a phrase, not a sentence, and never a whole paragraph. If the link approaches a full line, shorten the phrase, not the type size.
Do not repeat a link text for different destinations
Avoid the same link text with different destinations on one page, such as “Read more” five times. Differentiate them.
Use a verb for an action, and name the document
Name the exact action or document the link opens, and for a quote or an order the stage the user is in. Include the quote number when you refer to a specific quote. Examples for common B2B flows, one example per line:
Company accounts and invoicing
Quotes and bulk orders
Reordering and order history
Stock, stores and delivery
Workwear and sizing for teams
Product documentation and compliance

Do
  • Link the words that name the destination (“product page”), not “click here”.
  • Give the link the same style as the surrounding text: size, line height, letter spacing, weight and italic.
  • Remove the link or show plain text when the destination is not available.
  • Give the link the same color as the surrounding text: Primary, Secondary or Tertiary, with the matching hover color.
  • Use Inverted on dark surfaces.
  • Keep the underline on default links in running text: color alone is not enough (WCAG 1.4.1).
  • Keep the link text short: a phrase, not a sentence.
  • Use Medium, Bold or Italic only when the text around the link has that style.
  • If a link opens a new tab (PDF, for example), say so and add rel="noopener".
Don’t
  • Add an icon to an inline link.
  • Remove the underline in the enabled state (use the reverse underline on purpose).
  • Make a link larger, bolder or more italic than its text for emphasis.
  • Disable a link.
  • Use an inline link on its own line (use Action link).
  • Link whole sentences or wrap a paragraph in a link.
  • Link filler words (“click here”, “read more” alone).
  • Use the default dark link on a dark background.
  • Bold every link.
  • Open new tabs by default.
  • Use a web address as the link text.




Anatomy
Inline link
  1. Link text. The words that name the destination, in text-action-primary (Primary). The size follows the text around the link.
  2. Underline. Shown when enabled, removed on hover. It is never animated.
An inline link has no icon (an Action link always has one), no padding and no background. It is a real <a href> inside the text.




Variants
Four colors. A link has the same color as the text around it: Primary, Secondary or Tertiary, and Inverted on dark surfaces. Each has its own hover color (text-action-primary-hover, text-action-secondary-hover, text-action-tertiary-hover and text-action-primary-inverted-hover). Sizes are under Sizes below; weight, italic and reverse underline follow after Inverted.
Colors
A link has the same color as the text around it. In Primary text the link is Primary, in Secondary text Secondary, in Tertiary text Tertiary. The surrounding text has the same color as the link in the examples.
Inverted
On a dark surface. Use it where the Primary link would not have enough contrast.
Weight
Regular is the default. Medium (500) and Bold (600) follow the weight of the text around the link: a link in a bold text is Bold. They are not a way to emphasize a link. Any size can have any weight.
Italic
Add inline-link--italic when the text around the link is italic. The font has an italic face for every weight.
Reverse underline
inline-link--reverse (Figma “Reverse”) has no underline when enabled and shows it on hover, like an Action link. Use it where the surrounding text already makes it clear that the words are a link; color alone is not enough (WCAG 1.4.1).




Sizes
An inline link matches the context it is in: XLarge, Large, Medium or Small, aligned to body-xl, body-lg, body-md or body-sm. It must match the size, line height and letter spacing of its surrounding text, and follow the Desktop or Mobile base styles that text follows. Never make a link larger or bolder than its text for emphasis. If a link stands apart from other content, its size matches the default body copy size of the page. XLarge, Large and Medium change at 769px; Small is the same on every breakpoint. The values are under Sizes in Specifications.

Layout & Appearance
Alignment
An inline link is part of the text flow: it wraps with the text and takes its line height from the size.
Placement
Only inside running text: body copy, a list or UI text. A link on its own line is an Action link.
Width
As wide as its text (display: inline).
Appearance
Underlined when enabled. On hover the underline goes and the color changes. This is the reverse of the Action link, unless the reverse underline is used (underline on hover only). Token names and values are under Design Tokens in Specifications.




Behavior
Hover
The underline is removed and the color changes to the hover color of the variant. The color changes over duration-fast-3 with ease-standard; the underline is not transitioned.
Click and Enter
A click or Enter follows the link. All states are listed under States in Specifications.
Focus
A 2px ring shows on keyboard focus only (body.keyboard-nav), the same as on the Action link and the Tile link.




Accessibility
All requirements are listed under Accessibility Requirements in Specifications.
Keyboard support
Tab moves between links. Enter follows the focused link.
Screen reader support
A real <a href> is announced as a link, with its text. Write link text that makes sense out of context. Links navigate; buttons act.
