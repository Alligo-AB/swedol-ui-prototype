Overview
Icons symbolize common actions, features and themes in our products. They help a person recognize a function quickly, and they work together with a text label.
The icon set has two sources. Material Symbols is the base: Outlined for the normal state and Fill for the active state. Custom icons cover what Material Symbols does not: customized symbols, brand icons for Swedol and Tools, social icons and logos.
This documentation has three pages. Examples & Guidelines (this page) shows when and how to use icons. Specifications holds the Material Symbols settings, sizes, color tokens and the icon item. Code shows how to add an icon to a page.
Two more pages belong to the icons: the Library (search and copy the name of every icon) and Add an icon (how a designer adds an icon to the system).




Usage
When to use
Use an icon to support a label or to name an action that is known from experience. Use it to:
  • Mark an action in a button, a menu item or a list item, next to its label
  • Show a status or a type, for example in a notification or a badge
  • Name an action in a toolbar, with a Tooltip when there is no label
When not to use
To decorate
Do not add an icon that carries no meaning. A page with many icons is harder to scan than a page with few.
To replace a label that is not known
Only the most common icons (search, close, menu, cart) are understood without a label. For everything else show a label too.
Quick reference
You need…Use
an icon from Material SymbolsA span.icon with the icon name
a customized, brand, social or logo iconAn inline svg.icon from the library
the active state of an iconThe Fill style (icon--fill)
a picture or an illustrationAn image, not an icon
Do
  • Use the same icon for the same meaning on every page.
  • Use Outline for the normal state and Fill for the active state.
  • Give an icon without a label an accessible name.
  • Link icon.css and use the size classes.
Don’t
  • Mix several icons for one meaning.
  • Scale an icon with a transform or a width and height of your own.
  • Use a color that is not a token.
  • Use an icon as the only way to read important information.




Variants
There are two sources and four custom groups. Every icon is drawn on a 24px grid.
Material Symbols
Outline (Fill 0, Weight 300) is the default. Fill (Fill 1, Weight 300) is the active state: use it for a toggled or selected icon, for example a cart that holds a product. It is for developers and is not listed in the Library. The icon names are the Material Symbols names.
Custom icons
Custom icons are inline SVG with the name of the icon ending in what they are. They use currentColor, so they follow the color of the icon class like a font icon does.
GroupName ends withHolds
Customized symbols_customMaterial Symbols that are changed, or new icons in the style of Material Symbols.
Brand_brandIcons that are specific to Swedol and Tools, for example the service icons.
Social_socialIcons of social media.
Logo_logoLogos of other companies, for example BankID.

Sizes
Standard icon sizes are 20px, 24px, 40px and 48px. The extra sizes 12px and 14px are reserved for badges and components with restricted space. Material Symbols uses the optical size that fits: 20 for 12, 14 and 20, then 24, 40 and 48.
SizeClassSize in pxWhen
XXSmallicon--xxs12Extra size, reserved for badges and components with restricted space.
XSmallicon--xs14Extra size, reserved for badges and components with restricted space (for example beside 14px text).
Smallicon--sm20The default inside controls: buttons, inputs, list items and menus.
Mediumicon--md24A stand-alone icon, for example an icon-only button, navigation or a notification.
Largeicon--lg40A tile, an empty state, a list of icons (the icon library).
XLargeicon--xl48A prominent icon, for example on a large tile. Use rarely.
The first sentence of the description is the Figma guidance. The examples in the table are ours.




Color
An icon is icon-primary on a light surface and icon-inverted on a dark one. Inside a button or a link the icon takes the color of its parent (icon--inherit). Never choose another color.




Behavior
An icon on its own does nothing. It is shown inside a component that has the behavior: a Button, a link, a menu item or a switch.
Active state
An icon that shows a state (a favorite, a selected filter) changes from Outline to Fill when it is on. The fill is the only change; the size and the color stay.
Inside a button
Use the Button’s own icon slot; the Button sets the size. An icon button with no label gets a Tooltip.




Accessibility
Requirements are listed under Accessibility Requirements in Specifications.
Screen reader support
A decorative icon, next to a label, is aria-hidden="true". An icon that carries the meaning on its own needs an accessible name: aria-label on the button or link that holds it, or a role and a name on a stand-alone icon.
Contrast
icon-primary and icon-inverted meet 3:1 against their surfaces (WCAG 1.4.11). Do not set another color on an icon that carries meaning.
