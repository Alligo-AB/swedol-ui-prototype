Checkbox

A checkbox lets the user turn one or more options on or off, independently of each other. The choice is saved when the form is submitted.

Tokens, sizes, measurements, states and requirements. Values come from the live token package and from Figma: Checkbox.

Motion

None. The checkbox changes state at once, with no transition and no animation.

Behavior

InputResult
Click box or labelToggles checked. Clearing the mixed state also makes it checked.
Tab / Shift+TabMoves between checkboxes. The focus ring shows with :focus-visible only.
SpaceToggles the focused checkbox.
MixedSet input.indeterminate = true in JavaScript. It cannot be set in HTML.
DisabledNot focusable, no hover. The label turns text-disabled through :has(input:disabled).
Without labelAdd aria-label. Never use an image or SVG file for the box.

Accessibility Requirements

TopicRequirement
ElementA native <input type="checkbox">. The role, the state and the keyboard behavior come from the browser.
NameA visible <label>, or aria-label when there is no text (Inline menu, tiles, table rows).
GroupRelated checkboxes in a <fieldset> with a <legend>.
MixedSet with indeterminate in JavaScript, so assistive technology reads “mixed”.
FocusRing with border-focus, 2px, offset 2px, on :focus-visible (WCAG 2.4.7, 1.4.11).
DisabledNot focusable. The label and the box use disabled tokens, which are exempt from contrast requirements.
TilesNo visible label: aria-label is required. On a PDP, show the name of the chosen option next to the group so the choice is not carried by the picture alone.
ColorSelected is not shown by color alone: it adds a checkmark (box) or a thicker frame (tile).
