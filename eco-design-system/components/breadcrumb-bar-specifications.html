Breadcrumb Bar

A breadcrumb bar shows where the page sits in the site and lets the user go back up in one click. Two to six crumbs, separated by a slash.

Tokens, sizes, measurements and requirements. Values come from the live token package and from Figma: Breadcrumb Bar.

Width

The bar is as wide as the page content. The crumbs keep their own width and wrap to the next row when the row is full.

Motion

The bar does not move. Only the text color of a crumb changes on hover: see Breadcrumb Base.

Behavior

TopicResult
PlacementFirst in .page, directly under the header, before the title block. The block that follows zeroes its top padding.
WrappingThe crumbs wrap to a new row when the trail is too long. A crumb never wraps its label.
BreakpointThe sizes change at 769px. sm looks like mobile.
BackgroundNone. It takes the page background: white or, on My Pages, grey.

Accessibility Requirements

TopicRequirement
Landmarknav[aria-label="Breadcrumb"].
LinksEvery crumb but the last is an <a href>. The last is a span with aria-current="page".
SeparatorA “/” character that adds no meaning. Hide it from screen readers when you build the markup with a list; the shipped markup keeps it as text.
OrderThe crumbs are in DOM order from Home to the current page.
FocusA visible focus ring on every link (WCAG 2.4.7).
ContrastText must reach 4.5:1 on the page background, white or grey (WCAG 1.4.3).
