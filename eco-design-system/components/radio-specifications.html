Radio button

A radio button lets the user choose exactly one of two or more mutually exclusive options. Choosing one clears the others in the group.

Tokens, sizes, measurements, states and requirements. Values come from the live token package and from Figma: Radio Button.

Width

An option is as wide as its label. The click target is the whole label.

Motion

None. The radio changes state at once, with no transition and no animation.

Behavior

InputResult
Click circle or labelSelects that option and clears the others in the group.
TabEnters the group once (the selected radio, or the first). The ring shows on keyboard focus only.
Arrow keysMove and select the next or previous option in the group. Native: needs the same name.
Groupfieldset with a legend; every radio shares one name.
DisabledNot focusable. Grey fill, light border, text-disabled label and message.
DefaultPreselect one option in every group unless the user must choose consciously.

Accessibility Requirements

TopicRequirement
ElementA native <input type="radio">. The role, the state and the arrow-key behavior come from the browser.
GroupA <fieldset> with a <legend>; every radio shares one name.
NameThe input and the text are wrapped in one <label>.
FocusRing with border-focus, 2px, offset 2px, on :focus-visible (WCAG 2.4.7, 1.4.11).
ColorSelected is not shown by color alone: the dot is a shape and the border is thicker in color.
DisabledNot focusable. Disabled tokens are exempt from contrast requirements.
