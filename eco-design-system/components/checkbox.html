Checkbox

A checkbox lets the user turn one or more options on or off, independently of each other. The choice is saved when the form is submitted.

Every example on this page is the real component. Click, tab and press Space to try it. Specification: .claude/skills/eco-checkbox/SKILL.md.

Variants

    
Two sizes (Large, Small), two modes (light, dark) and two types (standard, inline menu). Figma also has a Breakpoint property (XLarge–Medium and Small–XSmall), which only changes the Large label size (use the Breakpoint toggle to preview it): see Anatomy & specs. Choose the mode to see every variant below on a light or a dark surface.

Sizes

    
Large is the default. Small (class .form-checkbox-item--sm) is for dense layouts such as tables and filters.

    

      

    


    
With label, without label

    
A visible label is the default. A checkbox without a label needs an aria-label, and is only for dense cases such as table rows.

    

      

    


    
Group

    
Related options go in a fieldset with a legend. Stack them in a column, or wrap them in a row when the labels are short.

    

      

        

        

      

    


    
Select all (mixed)

    
A parent checkbox shows the mixed state when only some children are selected. Click the parent to select or clear all. This is the only case where the mixed state is used.

    

      

      

    


    
Inline menu

    
A checkbox with a dropdown arrow, for example a table header where the checkbox selects all rows and the arrow opens a menu (class .form-checkbox-item--menu markup below). It has no label, so it needs an aria-label. States: enabled, hover, focus and disabled, each unchecked, checked or mixed. The menu itself is not part of this component.

    

      

    


    
Check icon in a table

    
Read-only, to show whether a role has a permission. Always disabled, light mode only (class .check-icon on the cell).

Tiles

    
Checkbox tiles are used first and foremost on product pages (PDP) and in filtering, where the choice is a picture or a color instead of a text label. They are native checkboxes, so several can be chosen. Three kinds: Color swatch, Image and Number (the “+10” tile that shows how many more there are). They have no label, so each needs an aria-label.

    
Breakpoint
      


    
Color swatch in a filter list

    
A 24×24px tile with a 16px square of the product color. The same size on desktop and mobile. The color is the product’s own, set with the --swatch variable. In filtering several colors can be chosen, so these are checkboxes.

    

    
The same tiles as a compact grid, all 26 product colors:

    

    
The swatch shows the product color, including the glossy gradients and finishes (gold, mirror lens, semi shiny, transparent, pattern). The library below has all 26 product colors from Figma, each with its name in alt-label-lg style (Medium, uppercase, text-tertiary) and a 16px swatch. In the real filter the hex value comes from the product data.

    


    
Image on a product page

    
The product picture inside a 48px tile (40px on mobile), with 6px around the image. On a product page (PDP) only one can be chosen at a time, so the tiles are radio inputs with the same tile styling (use checkboxes only when several can be chosen, as in filtering). The Number tile (“+10”) has the same size and sits last in the row.

    


    
States

    
Enabled, hover, selected and selected hover for each tile. Hover is forced on this page. The Number tile only has enabled and hover in Figma.

Selected is a 2px frame, drawn as a 1px border plus a 1px inset line so the tile never changes size. Disabled is not defined in Figma for tiles.

Behavior and accessibility

    

      
InputResult

      
        
Click box or labelToggles checked. Clearing the mixed state also makes it checked.

        
Tab / Shift+TabMoves between checkboxes. The focus ring shows with :focus-visible only.

        
SpaceToggles the focused checkbox.

        
MixedSet input.indeterminate = true in JavaScript. It cannot be set in HTML.

        
DisabledNot focusable, no hover. The label turns text-disabled through :has(input:disabled).

        
Without labelAdd aria-label. Never use an image or SVG file for the box.

Usage

    
Checkbox, radio and switch look alike but do different jobs. Choose by what the user is deciding.

    

      
The user…Use

      
        
picks any number of options, saved on submitCheckbox

        
picks exactly one of two or more optionseco-radio

        
turns a setting on or off, with immediate effecteco-switch

      

    

      

        
Do

        
    
          
  • Write labels that make sense when checked, in sentence case.
    • 
          
  • Group related checkboxes in a fieldset with a legend.
    • 
          
  • Use .form-checkbox-item--dark on dark surfaces.
    • 
          
  • Use the mixed state only for a “select all” parent.
    • 
        

      

      

        
Don’t

        
    
          
  • Use a checkbox for a choice between options. Use radio.
    • 
          
  • Use a checkbox for an on/off setting that applies at once. Use switch.
    • 
          
  • Put the light markup on a dark surface, or the dark markup on a light one.
    • 
          
  • Build the box from an image or SVG file, or hardcode its colors.
