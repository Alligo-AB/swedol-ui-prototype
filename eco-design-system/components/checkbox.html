Overview
A checkbox lets the user turn one or more options on or off, independently of each other. The choice is saved when the form is submitted.
Checkbox has two sizes (Large, Small), a light and a dark mode, an Inline menu type for table headers, a read-only check icon for tables, and tiles (color swatch, image, number) for product pages and filtering.
This documentation has three pages. Examples & Guidelines (this page) shows when and how to use a checkbox. Specifications holds the values: tokens, sizes, measurements, states and requirements. Code shows how to add a checkbox to a page.




Usage
When to use
Use a checkbox when the user picks any number of options, or confirms one option, and the choice is saved when the form is submitted. Use it to:
  • Choose any number of options from a list
  • Select all or some items with a parent checkbox that shows the mixed state
  • Select rows in a table, with the Inline menu type in the table header
  • Show whether a role has a permission, with the read-only check icon in a table
  • Choose colors or pictures in a filter or on a product page, with a tile
When not to use
Checkbox or radio button
Checkbox, radio and switch look alike but do different jobs. Use checkboxes when several options can be chosen. When exactly one of two or more options can be chosen, use eco-radio.
For a setting that applies at once
A checkbox is saved when the form is submitted. For a setting that turns on or off with immediate effect, use eco-switch.
Groups need a legend
Related checkboxes go in a fieldset with a legend, so a screen reader reads the question with each option.
Mixed is for a select-all parent
The mixed state says that some, but not all, of the children are selected. A checkbox with no children is either checked or not.

Do
  • Write labels that make sense when checked, in sentence case.
  • Group related checkboxes in a fieldset with a legend.
  • Use .form-checkbox-item--dark on dark surfaces.
  • Use the mixed state only for a “select all” parent.
Don’t
  • Use a checkbox for a choice between options. Use radio.
  • Use a checkbox for an on/off setting that applies at once. Use switch.
  • Put the light markup on a dark surface, or the dark markup on a light one.
  • Build the box from an image or SVG file, or hardcode its colors.




Anatomy
Checkbox
  1. Area. 24×24px: the box plus a 4px margin. The margin leaves exactly room for the focus ring (2px gap plus 2px line), so focusing never shifts the layout.
  2. Box. 16×16px with a 1px border. In dark mode the border is 2px on hover.
  3. Checkmark. White, drawn as an SVG background. Mixed shows a dash instead. Never an image file.
  4. Label. Breuer Condensed, body-md. 8px from the box. A checkbox without a label needs an aria-label.
Inline menu
The box followed by a 24×24px dropdown arrow, with no label. Dimensions are under Sizes in Specifications.
Tile
  1. Frame. The tile box, 48×48px (40×40px on mobile). A 1px border; selected is a 2px frame.
  2. Content. A picture 6px from the edge (image tile), a 16px swatch of the product color (color swatch) or the text “+10” (number tile).




Variants
Two modes (light, dark) and two types (standard, inline menu), plus the read-only check icon for tables. Choose the mode to see every variant on a light or a dark surface. With label, without label
A visible label is the default. A checkbox without a label needs an aria-label, and is only for dense cases such as table rows.
Select all (mixed)
A parent checkbox shows the mixed state when only some children are selected. Click the parent to select or clear all. This is the only case where the mixed state is used.
Inline menu
A checkbox with a dropdown arrow, for example a table header where the checkbox selects all rows and the arrow opens a menu (class .form-checkbox-item--menu markup below). Tiles
Checkbox tiles are used first and foremost on product pages (PDP) and in filtering, where the choice is a picture or a color instead of a text label. They are native checkboxes, so several can be chosen. Three kinds: Color swatch, Image and Number (the “+10” tile that shows how many more there are). They have no label, so each needs an aria-label. Figma: Color swatch and Image and Number.

Sizes
A checkbox has two sizes. Large is the default. Small (class .form-checkbox-item--sm) is for dense layouts such as tables and filters. Measurements are under Sizes in Specifications.




Layout & Appearance
Grouping
Related options go in a fieldset with a legend. Stack them in a column, or wrap them in a row when the labels are short.
Appearance
A checkbox is a 16px box with a 1px grey border that fills black when selected. Use the light version on light surfaces and the dark version (.form-checkbox-item--dark) on dark ones: surface-100 or surface-80. Never mix them. The label is 16/22 on mobile and 17/24 from 769px. Token names and values are under Design Tokens in Specifications.




Behavior
Selecting
A click on the box or the label toggles the checkbox. Clearing the mixed state also makes it checked. Space toggles the focused checkbox.
Hover and focus
Hover changes the fill and the border color. The focus ring (2px line, 2px offset) shows with :focus-visible only, so a mouse click does not draw it. The 4px margin around the box leaves room for it. All states are listed under States in Specifications.
Mixed
The mixed state belongs to a “select all” parent. It shows when only some of the children are selected, and is set with input.indeterminate = true in JavaScript: it cannot be set in HTML.
Disabled
A disabled checkbox cannot be focused and has no hover. The label turns text-disabled through :has(input:disabled).




Accessibility
A checkbox is a native <input type="checkbox">, so the browser and the screen reader do most of the work. All requirements are listed under Accessibility Requirements in Specifications.
Keyboard support
Tab and Shift+Tab move between checkboxes. Space toggles the focused one. The focus ring shows with :focus-visible.
Screen reader support
Every checkbox needs a name: a visible label in the label element, or an aria-label when there is none (Inline menu, tiles, table rows). Group related checkboxes in a fieldset with a legend. Never build the box from an image or an SVG file.
