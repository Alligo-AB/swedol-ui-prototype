Cards

A card groups an image, text, badges and links about one subject, and links onward to it. Read this page to pick the right card and find where it is documented.

Overview

Cards promote or summarise content: an article, a campaign, a brand, a role. They sit in a grid or a carousel, so every card in a set has the same structure and the same size rules.
