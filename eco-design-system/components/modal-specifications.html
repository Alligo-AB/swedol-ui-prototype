Modal

A modal is the most disruptive notification. It blocks the page until the user makes a decision, so use it only when the user must confirm or choose before going on.

Tokens, sizes, measurements and requirements. Values come from the live token package and from E-Com Modal.

The panel is never wider than the window: max-width: calc(100vw - 32px) and max-height: calc(100dvh - 32px); longer content scrolls inside the panel. On mobile Small keeps 16px to the edges (max-width: calc(100vw - 32px), 343px on a 375px viewport). Large is top: 0; left: 0; width: 100%; height: 100dvh; max-width: none, so it has no margin to the screen.

Motion

MotionPropertyDurationEasing
EnterOverlay: opacity. Panel: opacity and translate from 48px below (space-48) to 0duration-fast-4 (200ms), --modal-in-durationease-decelerate-emphasized, --modal-in-ease
ExitOverlay: opacity. Panel: opacity and translate from 0 to 48px below (space-48)duration-fast-3 (150ms), --modal-out-durationease-accelerate-generic, --modal-out-ease

A short move (48px) with the fade, no scale. Why 48px, and why no token: the move is short (a small share of the view), so it uses the Fast durations of eco-motion; 48px is a trial (24px was the first value): it is a clear lift, and still a short move, so the Fast durations apply. The value is space-48, an existing spacing token, written in the keyframes. There is no distance token and no custom property for it: Carbon, Adobe Spectrum and Atlassian keep duration and easing as the motion tokens and leave the travel distance to the component (Atlassian puts it inside a per-component token such as motion.modal.enterModal). Add a shared distance scale only if a second component needs the same move. The panel uses translate, not transform, so the centering is untouched. The exit is shorter than the enter and accelerates, as when an element disappears (eco-motion); Material, Carbon and Atlassian also close faster than they open. The script adds is-leaving and removes the dialog when the animation has run. Reduced motion: no fade, removed at once. Compare other values in the live Motion section on Examples & Guidelines.
