Tabs

Tabs organise content across screens, data sets and interactions at the same level of hierarchy. A tab bar lets the user move between groups of related content without leaving the page. For content that must be read in order, use steps instead.

Tokens, sizes, measurements, states and requirements. Values come from the live token package and from Figma: Tab items, Tab bar sizes, Tab info.

Measurements

Dimensions

Padding of one tab. Below the label (or the icon) sits the gap to the line plus the 2px line: 14px on desktop Large and Medium. Secondary tabs also have 16px on each side, so the line is wider than the label. Primary tabs have no side padding: the gap between them is 24px. The numbers are read from the component.

States

Enabled, hover, active and focus. Focus is a 2px ring around icon and label, on an enabled or an active tab alike; the line stays visible below it. Hover and focus are forced on this page. Figma has no disabled state, so none is built.

Width

Figma bars hug their content (the divider ends at the last tab). The component fills its container, per the overflow information in Figma. Say if hugging is wanted.

Label and icon colourInstant—

Content tabs: the line slides to the clicked tab (tabs.js moves one .tab-bar__indicator). Link tabs slide across the page change: a click keeps the hover look, the next page starts the line under the old tab and slides it to the new one (the old index is kept in sessionStorage for 5 s; the bar needs the same aria-label on every page). The tab the line is travelling to keeps its grey hover line until the sliding line has arrived over it. All of it is off under reduced motion.

Behavior

TopicRule
KeyboardTab moves into the bar, Left and Right switch tab (they wrap), Home and End go to the first and last. A tab opens as soon as it is focused. tabs.js does this.
Content tabsThe selected tab has tabindex="0", the others -1. Exactly one tab is active.
Navigation tabsLinks in a nav, the current page has aria-current="page". Link tabs.js for the sliding line.
Accent colourThe active line is black (surface-100) by default. Where a product uses its accent colour, set --tab-line-active on the bar: Swedol --color-accent-default; Tools is a primitive in the package (--color-primitive-color-brand-tools-accent-brand). The My Pages prototype pages use var(--brand), their own accent alias. Never restyle .tab::after or .tab-bar__indicator.
OverflowThe bar scrolls sideways with the scrollbar hidden; the active tab is scrolled into view. The divider runs the full width.
On-page navigationnav.tab-bar.tab-bar--page with a.tab whose href is #section-id. The bar is sticky (--tab-sticky-top). Scrollspy: the current tab is the last section whose top is above a line 25% down the visible area; at the end of the page it is the last section. The tab gets aria-current="location" and the line slides to it. Click: scrolls so the section starts under the bar (plus the section’s scroll-margin-top), 150 / 200 / 300 / 450 ms by distance (duration-fast-3, fast-4, medium-2, slow-1), ease-decelerate-generic; instant under reduced motion; wheel, touch or a key stops it. Focus moves to the section (tabindex="-1") and the #hash is added (data-tabs-hash="off" keeps the address). A scrolling box instead of the window works too (the nearest scrollable parent of the sections). Any number of sections: the bar scrolls sideways and keeps the current tab in view.

Accessibility Requirements

TopicRequirement
Content tabsrole="tablist" on the bar, role="tab" on each tab (button) with aria-selected and aria-controls, role="tabpanel" with aria-labelledby on the content. The selected tab has tabindex="0", the others -1.
Navigation tabsLinks in a nav with an aria-label; the current page has aria-current="page".
Icon onlyNeeds an aria-label. A status dot or number needs a text alternative where its meaning is not clear.
Focus2px ring border-focus on :focus-visible (WCAG 2.4.7, 1.4.11). The active line stays visible.
MotionThe sliding line is off under prefers-reduced-motion (WCAG 2.3.3).
On-page navigationThe current tab has aria-current="location". A click moves focus to the section, so a keyboard user continues reading there. The bar has an aria-label such as “On this page”.
NeverA tab as a div with a click handler.
