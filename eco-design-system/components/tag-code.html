Tag

A tag shows an active filter above a product list or a search result. Its × button removes the filter.

How to add a tag to a page. The file is components/css/tag.css.

Examples & GuidelinesSpecificationsCode

Basic Usage

Link the shared stylesheet once per page. Never copy the rules into a page.

StepWhat to do
1. Link<link rel="stylesheet" href="/components/css/tag.css">. Both templates already have it.
2. TagA span.tag with the label.
3. Variant and sizeAdd tag--white and/or tag--sm.
4. RemoveAdd tag--remove and a button.tag__remove after the label. Your script removes the tag and moves focus.

API

Classes

ClassUse
tagThe tag: Medium, Grey.
tag--whiteWhite surface, for grey backgrounds.
tag--smSmall.
tag--removeRemove state: padding for the ×.
tag__removeThe × button.

Things to know

  • There is no shared script: removing a tag is page logic.
  • Put tags in a flex row with gap: var(--dimension-spacing-space-8) and flex-wrap: wrap.
  • A status on a docs page or card is a Badge, not this component.

CSS / Tailwind
