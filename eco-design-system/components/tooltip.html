Tooltip

A tooltip gives an icon-only button a short name when the user hovers it. It is never shown on keyboard focus.

Every example on this page is the real component, not a picture. Specification: .claude/skills/eco-tooltip/SKILL.md. Figma: Tooltip.

Usage
The element…Use
is an icon button with no visible textTooltip
has a visible labelNo tooltip
needs more than a few wordsInline notification or help text
must work on touchNot a tooltip: it needs hover
Do
  • Name the action in 1–3 words.
  • Match the button’s aria-label.
  • Leave room for the tooltip on the side you choose.
  • Use Small in toolbars and table rows.
Don’t
  • Show it on keyboard focus.
  • Put essential information in it.
  • Put links or buttons in it.
  • Use it on elements that already have text.
