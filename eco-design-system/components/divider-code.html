Divider

A divider is a 1px line that separates content groups, so users can scan and organize information. It is decorative and never interactive.

How to add a divider to a page. The file is components/css/divider.css.

Examples & GuidelinesSpecificationsCode

Basic Usage

Link the shared stylesheet once per page. Never copy the rules into a page.

StepWhat to do
1. Link<link rel="stylesheet" href="/components/css/divider.css">. Both templates already have it.
2. HorizontalAn <hr class="divider"> between the two groups.
3. VerticalA span.divider.divider--vertical with role="separator" inside a flex row.
4. ColorPrimary is the default. Add divider--secondary or divider--tertiary.
5. SpaceSet it with the gap of the parent, never with margin on the divider.

Things to know

  • A divider is the same on every breakpoint.
  • The divider sets margin: 0. Put the space on the parent with gap.
  • A boundary between full-width page sections is .page-divider (eco-section), not a divider.
