# Archived card visuals

Old visuals for the cards on the overview pages, kept so a card can be switched back.
Each file holds the old markup and where it goes.

- `button.html` – Button card, `components-overview.html` (CSS buttons "Primary / Secondary", replaced by the Hairline animation).
- `switch.html` – Switch card, `components-overview.html` (CSS switches "Email / SMS", replaced by the Hairline animation).
- `radio.html` – Radio card, `components-overview.html` and `overview.html` (CSS radios "Standard / Express", replaced by the Hairline animation).
